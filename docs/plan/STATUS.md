## ユーザーに聞くこと（まとめて聞く）
- 芦屋みっけの掲載ページのアドレスの形（公開ページのフッターからのリンク先）。今は仮の `https://ashiya-mikke.jp/spots/<ID>/`
- **ドメインは2つ要る**：編集画面・API 用（例 `app.<芦屋みっけのドメイン>`）と、お店の公開ページ用の別のドメイン（例 `mikke-site.jp` の `ashiyado.mikke-site.jp`）。同じ親ドメインにすると、お店のページから編集画面のログインを邪魔できてしまう（安全面の見直し L5）。公開ページ用のドメインを1つ取ってほしい
- 試し（staging）の公開ページのアドレス：本番と同じドメインの2段のサブドメイン（`ashiyado.staging.<ドメイン>`）は、Cloudflare の無料の証明書では使えない（有料の Advanced Certificate Manager が要る）。試しは別のドメインにするか、有料にするか（線 B の README）
