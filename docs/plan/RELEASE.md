# リリースの条件（v1：最初の1軒）

**リリース＝本物のお店1軒が、自分でログインして、スマホかパソコンで自分のサイトを直し、公開できて、その公開ページを誰でも見られる状態。** テンプレートは wa-01（芦屋堂の形）1つ。

各項目は、確かめ方（自動＝確認スクリプト・CI で判定／人＝人が触って確かめる）を持つ。**全部が「済」になったらリリース。** 項目を足す・外すときは DECISIONS.md に理由を書く。

## A. 編集（店主がサイトを直す）
| # | 条件 | 確かめ方 |
|---|---|---|
| A1 | 精査の問題 135 項目（tools/verify-audit）がすべて OK。保留にしたものは、ユーザーが「リリース後でよい」と決めたものだけ | 自動：`run_audit.sh` |
| A2 | これまでの決まりの確認（tools/verify-claudeai。P で PowerPoint にそろえて期待を直したものを含む）がすべて OK | 自動 |
| A3 | 絵で見て決める使いにくさ 19 個（F1 ほか）が、決めた形になっている | 人（まとめて1回）＋自動 |
| A4 | 4回目以降の精査（触り回す）で、新しい「事故」が 0 | 自動＋精査 |
| A5 | iPhone の Safari で、選ぶ・書き換え（日本語の変換）・写真の差し替え・公開ができる | 人（実機） |
| A6 | Mac の Chrome・Safari の本物の日本語入力で書き換えが壊れない | 人（実機） |

## B. アカウントと保存
| # | 条件 | 確かめ方 |
|---|---|---|
| B1 | メールアドレスでログインできる（リンクかコード）。パスワードは使わない | 自動（API の試験）＋人 |
| B2 | 店主は自分のお店だけを直せる。制作側（NitenLabs）はすべてのお店を直せる | 自動 |
| B3 | 下書きはサーバーに自動保存され、別の端末で開いても同じ。ブラウザを閉じても消えない | 自動 |
| B4 | 2つの端末・タブで同時に直したとき、片方の手直しが知らせなしに消えない | 自動 |
| B5 | 保存に失敗したら知らせ、つながり直したら自動で保存し直す | 自動 |
| B6 | 毎日のバックアップがあり、1日前の状態に戻せる | 自動＋人（1回戻してみる） |

## C. 写真
| # | 条件 | 確かめ方 |
|---|---|---|
| C1 | スマホのカメラロールから写真を選んで差し替え・追加できる（HEIC を含む） | 人（実機）＋自動（JPEG・PNG） |
| C2 | 写真は長い辺 2400px に縮め、位置情報を消して保存する | 自動 |
| C3 | 公開ページの写真は、画面の大きさに合った大きさで配る | 自動 |
| C4 | 古い版が使っている写真は、ゴミ箱に入れても消えない | 自動 |

## D. 公開と公開ページ
| # | 条件 | 確かめ方 |
|---|---|---|
| D1 | 「公開」で、数秒のうちに公開ページが新しくなる | 自動 |
| D2 | 公開ページは、プレビューと同じ形（±0.5px）。PC とスマホの両方 | 自動 |
| D3 | 公開ページのアドレス：お店ごとのサブドメイン（例 `ashiyado.<ドメイン>`）。独自ドメインは v1 では制作側が手で設定 | 自動＋人 |
| D4 | 履歴から前の版を見て、下書きに戻せる | 自動 |
| D5 | 検索・共有の情報（タイトル・説明・共有の画像・お店の住所や営業時間の構造化データ・サイトマップ・見つからないページ）を自動で出す | 自動 |
| D6 | 出す月・販売の状態で品の出し入れが変わる（DATA_SPEC 3.4）。日付が変わったら公開ページも変わる | 自動 |
| D7 | 公開ページが速い（スマホで LCP 2.5 秒以内の目安） | 自動 |
| D8 | 芦屋みっけの掲載ページとの相互リンク | 自動 |

## E. 運用
| # | 条件 | 確かめ方 |
|---|---|---|
| E1 | 本番と試し（staging）の2つの環境。main に入ったものは試しへ自動で出る | 自動 |
| E2 | エラーが起きたら制作側に分かる（記録・通知） | 自動＋人 |
| E3 | 利用規約・プライバシーポリシー（店主向けサービスとして） | 人（文面は専門家確認） |
| E4 | 新しいお店をテンプレートから作る手順（制作側）が、手順書どおりに1時間以内でできる | 人 |

## F. 本物のお店で確かめる
| # | 条件 | 確かめ方 |
|---|---|---|
| F1 | 本物のお店の方 1〜2 人に「営業時間を変えて」「この写真を差し替えて」「公開して」と頼み、助けなしにできる | 人 |
