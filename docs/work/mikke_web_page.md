## 伝えること（11/9 の会話で、厳しめの評価を踏まえて決めた言い方）
- 芦屋のお店に、きちんとしたホームページを安く。初期 0 円・月額（料金と最低契約期間・解約時の扱いは**後で詰める**。決まるまで料金の欄は「お問い合わせください」か、決まった所だけ）
- 「食べログ・ホットペッパーの代わり」とは言わない。言うのは「ポータルとは別に、お店の正式な顔を安く持てる」。集客は約束しない
- **芦屋みっけへの掲載は無料、サイトの制作・保守は月額**、をはっきり分けて書く（混ざると「無料と言われたのに請求された」になる）
- 芦屋みっけが目指すもの：掲載料なしで芦屋のお店が集まり、人が行き交う場所。今は「準備中」と正直に書く
- 作例は**架空のお店と明記**（御菓子司 芦屋堂）。実在のお店の作例（李杏など）は許可が取れてから差し替える。作った口コミ・実績は載せない
