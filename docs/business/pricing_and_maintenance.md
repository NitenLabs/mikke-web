## 1. Web制作の価格戦略

### 確定した価格の型
- **初期費用：0円**
- **月額：4,980円前後**（実績ができ次第、値上げを想定。種まき期の現在価格という位置づけ）
- **最低契約期間：6〜12ヶ月**（途中解約は残債請求。初期無料の回収リスクをヘッジするため必須）
- 写真撮影はみっけ側で行わない前提（店舗が撮って送る）。プロ撮影は**有料オプション（+3〜5万円、半日想定）**として切り出す

### 価格設定の考え方
- 一般的なホームページ制作の相場（フリーランス15〜30万円＋月1万円、制作会社50万円超）と比較して安すぎるように見えるが、**比較対象は同業他社ではなく「無料のInstagram代替」**。個人店がWebを持たない最大の理由は費用より「固定客で足りる」という必要性の低さであり、値下げだけでは解決しない構造的な問題。
- 月額を「保守費」ではなく**「特集ページでの露出が続く広告費」**として売る。買い切り・格安サブスク競合（西宮・芦屋圏に初期0円/月9,800円等の実例あり）に価格だけで勝負すると負けるため、価格ではなく「継続露出込み」という価値で差別化する。
- 「買い切りでいいや」層は基本的に狙わない（値下げ合戦は利益とブランドの両方を毀損する）。狙うべきは①同じサブスク形態の競合（正面から価格で勝てる）、②非導入層（初期無料が刺さる）。

### 補助金の活用（実質負担を下げる営業トーク）
- **小規模事業者持続化補助金**：補助率2/3。ただし2026年の制度改定で「ウェブサイト関連費は単独申請不可、上限30万円（税込）」となったため、**看板・チラシ等の販促物とセットで申請する必要がある**（以前検討した「みっけ認定ステッカー・看板」のアイデアと相性が良い）。
- 芦屋市は**芦屋市商工会**の管轄（〒659-0065 芦屋市公光町4-28、TEL 0797-23-2071）。申請には商工会での様式4面談が必要。
- 次回申請枠（第20回）：申請受付**2026年11月5日〜12月15日**、様式4発行締切は12月4日。採択率は5割弱（保証はできない）。
- 補助金は後払い（精算払）のため、店舗側は一旦全額立替が必要。この点は正直に伝える。
- IT導入補助金（現・デジタル化AI導入補助金）は通常のサイト制作費は対象外（CRM・予約システム等のツール部分のみ対象）なので、基本サイト制作には使えない。

## 2. 芦屋市の対象店舗数データ（利益シミュレーションの基礎資料）

出典：芦屋市統計書 令和6年版（令和3年経済センサス‐活動調査時点のデータ）

| 業種 | 事業所数 |
|---|---|
| 飲食店 | 293 |
| 持ち帰り・配達飲食サービス業 | 35 |
| 洗濯・理容・美容・浴場業 | 205 |
| 飲食料品小売業（パン屋等含む） | 171 |
| 織物・衣服・身の回り品小売業 | 120 |
| その他の小売業 | 205 |

- 上位5業種の合計：**824件**。全業種合計だと約1,029件。
- 芦屋市の全事業所数は3,078件（令和3年、公務除く）だが、残りは不動産業・専門サービス業等、個人店向けWeb制作の対象外の業種が大半。
- **824〜1,029件が、みっけのWeb制作サービスの現実的な対象市場（TAM）**として今後の商談目標・導入率の議論の基礎に使える。

シミュレーション上の重要な気づき：導入率や価格そのものより、**「月次対応工数（1店舗あたり毎月何時間かかるか）」が利益を最も左右する変数**。ここがゼロに近いか、1時間を超えるかで、3年後の累計利益が大きく変わる。

## 3. 月次メンテナンス運用の設計原則（テンプレート量産前に確定させるべき最重要事項）

### 3.1 大原則：セルフ編集モデルを基本にする

食べログ・ホットペッパーの運用モデルを調査したところ、両社とも**日々の店舗データ編集はスタッフが一切行わず、店舗側が管理画面から完全セルフサービスで編集する**仕組みだった（人が関わるのは契約時の営業・オンボーディングと、お任せしたい店舗向けの有料代行サービスのみ）。

→ みっけも同じ発想を取る。**基本の更新はすべて店舗のセルフ編集にし、みっけの人力対応は「代行してほしい店舗向けの有料オプション」として明確に切り分ける。** これにより店舗数が増えてもみっけ側の基本コストは増えない。

### 3.2 コンテンツを3つの型に分類する

新しいテンプレートを作るたびに、以下の型のどれに当てはめるかを最初に決める。この判断さえ徹底すれば、テンプレートが何十種類に増えても崩れない。

| 型 | 特徴 | 例 |
|---|---|---|
| **固定スロット型** | 枠数がテンプレート側で決め打ち。何を入れ替えても崩れない。承認なしで即時差し替えOK | ヒーロー写真、代表メニュー〇品、店内写真〇枚、営業時間・定休日 |
| **リスト型** | 件数が可変。テンプレート側が「何個来ても崩れない」設計になっている必要がある | フルメニュー一覧（品名・価格・説明・写真は品ごとに任意） |
| **期限付き通知型** | 開始日・終了日をセットで持たせ、期限が来たら自動的に表示から消える | 長期の休業予定（年末年始等） |

- **凝ったデザイン・独特なレイアウトの部分には、固定スロット型だけを使う。** リスト型は「メニュー一覧ページ」のような事務的な場所に追い出す。これにより「独特なレイアウトを維持したい」という要望と「更新しやすさ」を両立できる。
- 写真の縦横比がバラバラでも枚数さえ固定なら崩れない。ただしアスペクト比の強制トリミング処理は別途必要。

### 3.3 廃止が決まった機能：「お知らせ」

- 当初検討していた「臨時休業・営業時間変更のお知らせ」機能は、**丸ごと廃止**が決定した。
- 理由：みっけは回遊型メディア（お店を発見するために見る）であり、「今日行くかどうか調べる」タイミングとサイト閲覧のタイミングが基本的にズレている。同日性の告知情報を載せても見られる確率がほぼゼロ。
- 即時性の高い情報（臨時休業、キャンペーン、イベント告知等）は**すべてSNS・LINEに譲る**。長期の特記事項（年末年始休業等）は、既存の「営業時間」フィールドに一言添える形で吸収し、新しい機能・レイアウトは作らない。

### 3.4 廃止・除外が決まった項目：販促系全般

以下は「即時性・宣伝性が命の情報はみっけの回遊型という使われ方と噛み合わない」という同じ原則で、業種を問わず全て除外し、SNS・LINEに譲る。
- イベント・コラボ告知
- キャンペーン告知
- セール情報
- 完売・入荷情報、満席・予約状況（そもそも対象外）

残った更新項目（季節・新メニュー、新商品入荷、施術事例写真等）は、新しい機能を作る必要はなく、**既存のメニューリスト・写真ギャラリーへの追加として扱えばよい**。

唯一「みっけの編集者としての価値」として意図的に人力に残すのは、**特集ページの鮮度維持**（新メニュー紹介の書き直し等）のみ。これは店舗都合の更新ではなく、みっけ自身の編集カレンダーの一部として管理する（店舗数に比例して労働が増えない）。

### 3.5 飲食店のメニュー機能の具体設計

- LP（ランディングページ）とは別に、テンプレートごとの「メニュー詳細ページ」を用意する。
- **パターン選択（写真ありモード／文字だけモード）は導入しない。** 実際の店舗は「看板メニューだけ良い写真があり、他はない」という混在が普通なため、モード選択は不要。
- 各品目を「写真（任意）＋品名＋価格＋説明」の1行として扱い、写真の有無に応じて行単位で表示を切り替える（条件表示）。
- この設計により、**フルメニューと写真ギャラリーを1つの機能に統合できる**（管理する可変長リストが2種類から1種類に減る）。
- この機能は飲食店系テンプレート向け。美容室等は価格表寄りのメニューになるため、同じ設計を流用するかは別途検討。

### 3.6 まとめ：最終的にテンプレートが持つべき機能一覧

1. **固定スロット型**：ヒーロー写真、代表写真・メニュー、店内写真、営業時間（特記事項込み）、定休日
2. **リスト型**：フルメニュー一覧（品ごとに写真任意）
3. **みっけの編集枠（店舗の自己更新の外）**：特集ページの鮮度維持

「お知らせ」「販促告知」等の独立機能は一切持たない。

## 4. LINE活用の構想（将来検討・実装は後回し）

- 検討した2つの方向性のうち、**「みっけ本体の読者獲得チャネル」としてのLINE公式アカウント**が本命という結論。狙いは、フォロワー数×開封率を「掲載する価値の証明」として数値化し、店舗への営業材料を強化すること。
- 「店舗向けの提供メニュー（Web制作とセット）」としてのLINE運用は、将来的な検討事項として保留。
- **今回の結論：LINEは実装フェーズの話ではなく、まだ構想段階。** フォロワー基盤を育てるなら種まき期のうちから並行して始める価値はあるが、優先度は今回のメンテナンス設計・価格戦略確定より低い。
