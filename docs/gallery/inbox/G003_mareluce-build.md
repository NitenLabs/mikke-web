## お店の設定（架空）
- 店名：**Trattoria Mareluce**（トラットリア マレルーチェ。「海の光」）。G001 の調べで重なりがあれば代わりの案の1つ目を使い、SPEC と報告に書く

- 雰囲気：明るく賑やか、家族や友人と。手打ちパスタ、薪窯のピッツァ、自然派ワイン。手書き風の差し色を少し
- 色：テラコッタ（#C2603F 前後）・生成り（#F7F1E8 前後）・オリーブ（#6B7045 前後）。コントラスト 4.5:1 以上（テラコッタの上の白文字は大きい文字だけ）
- 書体：欧文は個性のあるセリフ（例 Fraunces、DM Serif Display など）、和文は読みやすい丸すぎないゴシックか明朝。手書き風は見出しの飾りに1か所だけ
- 段（参考に合わせて増減してよい）：ファーストビュー／お店について／メニュー（前菜・パスタ・ピッツァ・メイン・ドルチェ）／おすすめ3品／ワイン／ランチ／営業案内・予約／アクセス（地図）／フッター
