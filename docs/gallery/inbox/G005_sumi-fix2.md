## 直すこと（G004 の後で、まだ残っていれば）
1. **季節の一品の「揚げ出し豆腐 舞茸の餡」の写真**に白い丸い傷が2か所ある（器の右上と下）。G004 で差し替わっていなければ差し替える。品名は写真の料理に合わせ、割烹の冬の品書きとしてもっともらしく（揚げ出し豆腐は居酒屋寄りなので、残すなら「蕪と湯葉の炊き合わせ」など格に合うものへ）
2. **用字の揺れ**：ファーストビューは「一碗の出汁に」、お料理の段の縦書きは「一椀に」。**「椀」にそろえる**（漆のお椀なので）。ほかにも同じ語の書き分けが無いか全文を見る
3. **ご挨拶の文の組み方**：12の文が1文ずつ中央揃えで並び、スマホでは中央揃えが25行続く。意味のまとまりで **3〜4段落** にまとめる。スマホは左揃え（PC は中央揃えのままでもよいが段落に）。文そのものは自然なので大きく変えない
4. **コース名を中身の分かる書き方に**：昼「おまかせ 季節の椀つき」は 6,600円の方との違いが分からない。例：昼「おまかせ（八寸・お造り・焼物・食事）6,600円」「おまかせ 品数多め 8,800円」、夜「おまかせ 15,400円」「おまかせ 冬の特選（蟹・河豚など）22,000円」
5. **お料理の帯の左端**：1枚目が半端に切れて見える（PC）。帯の左端を本文の左端にそろえるか、流れる帯なら切れ目が自然に見える作りに。白い背景の現代風の器の写真が残っていれば、他の写真と同じ暗めのトーンのものに替える
6. **PC 右上のメニューボタン（三本線）**：ファーストビューの左にナビがあるので重なって見える。スクロールしてナビが見えなくなってから出す、などにする（参考がそうでなければ参考に合わせてよい。報告に書く）
