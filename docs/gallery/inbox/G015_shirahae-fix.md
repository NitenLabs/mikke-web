## 直すこと
1. **Information の地図が空の深緑の箱になっている**（PC。右半分が何も無い色の面）。点検表の「浮いた色の面」に当たる。地図が出るようにする（澄・TIDE と同じ出し方。緯度経度＋拡大率で、Google の場所の札が出ない形）。撮影のときだけ読み込みが間に合わなかったなら、撮影の待ち方を直して撮り直す
2. **クリームソーダの写真が品書きと合っていない**：写真は緑の炭酸だけで、アイスクリームが乗っていない（説明は「バニラのアイスをのせて」）。**緑のソーダにアイスクリーム（できればさくらんぼ）が乗った写真**に差し替える。純喫茶らしいグラスが望ましい。見つからなければ、品を写真に合わせて「メロンソーダ」にし、説明もそろえる
3. **店内の段の写真と文の食い違い**：見出しは「深緑の椅子と、真鍮の灯り。」だが、写真は木の壁・額の絵・黄色い椅子の切れ端で、深緑の椅子も真鍮の灯りも写っていない。①写真を見出しに合う物（深緑のソファや椅子、真鍮のランプ）に差し替えるか、②見出しを写真に合う言葉に変える（例「木の壁と、古い額。」）。左下の椅子の切れ端の写真は、何が写っているか分かりにくいので替える
4. （小さい）「浅煎りストレート」は純喫茶の品書きとしては少し今風。「本日のストレート」など、喫茶店らしい呼び方でもよい（任せる）
