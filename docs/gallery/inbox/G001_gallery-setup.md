お店ごとに見本を作ってから営業するのをやめ、**架空のレストラン・カフェのサイトを10本** 作って紹介事例のギャラリーにする。オーナーさんはそこから選ぶか、参考を持ち寄ってこちらで作る（月額数千円）。**質を最優先**（「質はまじでこだわって」「変なところは提出前に精査して直して」）。

## やること
1. **始める前に** `mikke-web` で `git pull`。`CLAUDE.md` と `START_HERE.md` に従う。worktree `wt\gallery` を作る
2. **「架空のお店」の印をデータに足す**
   - お店のデータ（`samples/<店>/shop.json` か `site.json` の合う所）に「架空の見本」であることを示す項目を足す（名前は DATA_SPEC の流儀に合わせて決めてよい。例 `demo: true`）
   - それが立っているお店は、どの型（wa-01〜04 と今後の型）でも **フッターの一番下に小さく「このサイトは架空のお店のデザイン見本です（芦屋みっけ）」** が出るようにする。共通の部品で1か所に書く（型ごとに書かない）
   - データの形を変えるので、`schema/`・`docs/DATA_SPEC.md`・`tools/validate.mjs` をそろえて直し、`npm run validate` と `npm test` を通す
   - 試し：`samples/ashiyado`（架空の和菓子店）に印を立てて組み立て、フッターに出ることを確かめる。実在のお店（rian・roku・hamasyou・amet）には立てない
3. **店名の重なりを調べる**（10本のたたき台の店名。食べログで芦屋市・西宮市・神戸市東灘区に同じか紛らわしい名前の店が無いか。Google 検索でも1回）
   - 純喫茶 ひなた舎／TIDE COFFEE STAND／麦と灯（むぎとあかり）／Pâtisserie Lune Claire／日本料理 澄／鮨 一之汐／炭火焼肉 くろ炭／Trattoria Mareluce／Bistro à Vin Le Pivot／焼鳥 とりの音
   - 重なる・紛らわしいものは、同じ雰囲気の代わりの名前を2案ずつ出す（決めるのはユーザー）
4. **ギャラリーの入口ページのひな形**
   - 一覧のデータ（例 `data/gallery.json`：店のID・店名・ジャンル・雰囲気の一言・見本のパス）から、カードを並べた1枚のページを書き出す道具（例 `tools/gallery-export.mjs`）。出力先は `C:\Users\sea_p\GitHub\_preview\gallery\`（`preview-export` と同じく noindex）
   - カードには見本の縮小画像（PC のファーストビュー）を自動で撮って入れる。スマホ 390 で2列→1列に崩れず並ぶこと
   - 見た目は控えめで上品に（ギャラリーの主役は各お店のサイト）。芦屋みっけの名前と「掲載のお店はすべて架空です」の一文を入れる
   - 今は ashiyado の1件だけで動けばよい（10本は G002 以降で足す）
5. **自分で点検**：組み立てた ashiyado のフッターと、入口ページを PC 1440・スマホ 390 で全体像を1回ずつ見る（CLAUDE.md の点検の5項目）
