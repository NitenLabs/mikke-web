## 直すこと
1. **お料理の帯（4枚の写真）が割烹に合わない**
   - 今：アボカド巻きの入った寿司の盛り合わせ、サーモンの握り、白い背景の現代風の器。回転寿司や洋風のカフェに見え、割烹の格が下がる
   - 直し：割烹らしい写真に差し替える。例：椀物（蓋を開けた吸い物）、八寸、白身のお造り（鯛・平目など。サーモン・マグロの赤身・アボカドは使わない）、土鍋ご飯、カウンター越しの手元（顔は写さない）。**暗めの陰影でトーンをそろえる**（ファーストビューの写真に合わせる）
   - 帯の左端で1枚目が半端に切れて見える。帯の左端を本文の左端にそろえるか、流れる帯なら切れ目が自然に見える作りにする（PC で「切り損ね」に見えないこと）
2. **季節の一品**
   - 「揚げ出し豆腐 舞茸の餡」の写真に、白い丸い傷が2か所ある（器の右上と下）。差し替える
   - 品が居酒屋寄り（揚げ出し豆腐・温うどん）。割烹の冬の品書きにする。例：甘鯛の松笠焼き／蟹真丈の椀／鰤の照り焼き 柚子の香り／土鍋で炊く牡蠣ご飯 など
   - **写真と品名を必ず一致させる**（写真に写っている料理の名前にする）。4枚のトーンもそろえる
3. **用字の揺れ**：ファーストビューは「一碗の出汁に」、お料理の段の縦書きは「一椀に」。**「椀」にそろえる**（漆のお椀なので）。ほかにも同じ語の書き分けが無いか全文を見る
4. **ご挨拶の文の組み方**
   - 今：12の文が1文ずつ中央揃えで並び、スマホでは中央揃えが25行続く。読みにくく、散文詩のように見える
   - 直し：意味のまとまりで **3〜4段落** にまとめる。スマホは左揃え（PC は中央揃えのままでも、段落にする）。文そのものは自然なので大きく変えなくてよい
5. **コースの名前を中身の分かる書き方に**
   - 昼「おまかせ 季節の椀つき」は、6,600円の方にも椀が付くのが普通なので違いが分からない。例：昼「おまかせ（八寸・お造り・焼物・食事）6,600円」「おまかせ 品数多め 8,800円」、夜「おまかせ 15,400円」「おまかせ 冬の特選（蟹・河豚など）22,000円」
6. **PC 右上のメニューボタン（三本線）**：PC ではファーストビューの左にナビがあるので重なって見える。スクロールしてナビが見えなくなってから出す、などにする（参考がそうでなければ、参考に合わせてよい。報告に書く）
