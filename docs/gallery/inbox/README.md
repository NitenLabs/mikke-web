# ギャラリーの指示の受け方（実行役向け）

紹介事例ギャラリー（架空のお店10本）の指示は、受信箱でなくこのフォルダに `G00X_….md` として置く（相談役のチャットからパソコンの受信箱に書けないため）。

## 受け方
1. 自分のレーンの受信箱（`_mailbox\laneN\inbox`）が空いているときに、`git pull` してこのフォルダを見る
2. 番号の小さい順に、まだ誰も受けていない指示を1つ選ぶ。受けたかどうかは `docs/gallery/status/` の札で見る
   - 受ける前に `docs/gallery/status/G00X.laneN`（中身はレーン名と時刻の1行）を作って、すぐ commit して `git push origin HEAD:main`。push が競合したら pull して、札が他のレーンに取られていればその指示は飛ばす
   - 指示の中の「前提」（例：G001 が済んでいること）が済んでいなければ、その指示は飛ばして次を見る
3. 終わったら札を `docs/gallery/status/G00X.done` に変えて push。報告は自分のレーンの `reports\G00X_….md` と `reports\latest.md`
4. 次の指示があれば続けて受ける。無ければ自分のレーンの受信箱の見張りに戻り、ときどき（受信箱が空のとき）ここを pull して見る
- 実在のお店の指示（受信箱の `00xx`）が来ていれば、そちらを先にやる

## 相談役が見るための画像
- 相談役のチャットは `_preview\` を見られない。各お店の組み立てが済んだら、点検に使った全体像を **`docs/gallery/review/<店のID>/`** に置いて push する
  - `pc-1440.jpg`・`tab-768.jpg`・`sp-390.jpg`（ページ全体。幅はそのまま、JPEG の質 70 前後、1枚 2MB まで。長すぎるときは縦に分けて `-1`・`-2`）
  - 架空のお店で写真は Unsplash なので、公開リポジトリに置いてよい。**参考サイトの撮影画像は置かない**（.gitignore のとおり refs/ の画像は上げない）
