# fix01 §3.10 写真の候補（選ばない・並べるだけ）

作業票 §3.10 の指示どおり、枠 **C・D・E・J** を替える候補を各8枚ずつ集めた。**Claude Code は選ばない**（開くのは Claude.ai とユーザー）。
一覧画像は `refs/candidates/fix01-<枠>.jpg`（幅1200以内・番号つき）。SPEC 7.1 の「写してはいけないもの」（顔・人物〔手は可〕・文字〔看板/のれん/包装/ロゴ/寺社の印〕・海外/洋菓子）は alt テキストで除外したが、**文字・トーンの最終確認は一覧画像を開いて行うこと**（特に J の提灯・軒先の屋号文字）。参照元と同じ写真、既使用スラッグは除外済み。

§3.9 の訂正で **範囲外＝替える候補は C・H・I**（H・I は白背景/日中光で範囲外）。§3.10 の対象は C・D・E・J のため、**E は範囲内だが指示どおり候補を用意**し、**H・I の候補集めは未実施**（対象外のため。必要なら追加で集める）。
