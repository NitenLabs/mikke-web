## 2. 選んでからのドラッグ（X1）

PowerPoint のグループと同じにする。

- 表・品の並びが選ばれている状態で、中を押して**動かした**ら、全体が動く
- 押して**動かさずに離した**（クリック）ら、中の1件・文字が選ばれる（前の作業票の5章のまま）
- 押した瞬間には選び方を変えない。動いたか、動かずに離したかで決める（ほかの部品のドラッグ開始と同じ、少し動いたら「動かした」とみなす決まりを使う）

## 3. 縦積みの間隔の決まりの補足

`wa-01_layout_playground6_workorder.md` の2章の「塊の一番上・一番下の部品で、上（下）の隣がテンプレートにない → 0 とみなす」を、次に改める。**試験台7の作りがすでにこのとおり**なので、作りは変えなくてよい（確かめるだけ）。

- **塊のすぐ上・すぐ下にある物（セクションの見出しなど）も、間隔の決まりでは隣どうしとして扱う**。テンプレートで隣だった組はその間隔、初めて隣になった組は広い方
- 例（品のセクション）：テンプレートでは 見出し ─80／40─ 品の並び。区切り線を一番上へ動かすと、見出し ─120／98─ 区切り線 ─120／98─ 品の並び（見出しと区切り線は初めて隣なので広い方、区切り線と品の並びは元々隣どうし）
- 塊の一番下で、下に何もなければ 0

## 4. 大きさを変える

### 4.1 つまみ

部品を選ぶと、選んだ枠につまみを出す（PowerPoint と同じ見た目の小さな四角）。つまみの要素には `data-handle` に向き（`n` `s` `e` `w` `ne` `nw` `se` `sw`）を付ける。どの部品にどのつまみを出すかは、次の表のとおり。

| 部品 | 出すつまみ | 変わるもの |
|---|---|---|
| 文字（見出し・本文・営業時間・足した文字など） | 四隅、左右の辺、下の辺 | 四隅と左右の辺で横幅。下の辺で、文字の下に足す空き |
| 写真 | 四隅だけ | 縦横の比を保ったまま大きさ |
| 区切り線 | 左右の辺 | 横幅 |
| ボタン | 左右の辺 | 横幅（文字は真ん中のまま） |
| 表・品の並び | 出さない（今回は対象外。品の並び方と絡むため） | ― |

### 4.2 振る舞い

- **文字の高さは、文字に合わせて自動**（PowerPoint の既定と同じ）。横幅を狭めれば改行が増えて高くなる
- **文字の下の空き**：下の辺を下へ引くと、文字の下に空きが足される。上へ引いても、文字の高さより短くはならない（そこで止まる）
- **左の辺・左側の角で変えたときは、右端を動かさない**（その分、位置のずれとして記録する）。右側も同じく左端を動かさない
- **ページの中身の幅（左右の余白の内側）を越えて広げられない**。越えようとしたら、端で止まる（横のはみ出しを作らない）
- **小さくできるのは 40px まで**（横幅・写真の短い辺）
- **縦積みの中の部品が高くなったら、下の部品を押し下げる**。間隔は前の作業票までの決まりのまま
- **M2 の部品（塊の外へ出したもの）は、大きくして別の部品と重なっても押し下げない**。それは自分で重ねたものとして `ownerOverlaps` に入る
- **もう一方の端末は変わらない**（手で触った端末だけ変わる、これまでの決まり）
- 大きさを変えた後に文字を書き足したら、横幅はそのまま、高さが伸びて、下を押し下げる

### 4.3 記録

- 大きさは、手直しの性質「大きさ」として、部品 → 端末で記録する（DATA_SPEC の形）。値は設計の幅での px
  - 文字：`w`（横幅）と `padB`（文字の下に足した空き。なければ 0）
  - 写真：`w` と `h`
  - 区切り線・ボタン：`w`
- 「戻す」「やり直す」で、大きさの変更も1回ずつ戻る
- 「元の位置に戻す」（部品・セクション・ページ）で、大きさも戻る。戻るのは位置・大きさ・並び順・重なり順
- 入口：`window.__playground.sizes()` で、今の端末の大きさの手直しを `[{part, w, h?, padB?}]` で返す
