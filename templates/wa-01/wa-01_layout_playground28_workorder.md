## 2. 作ること

### 2.1 ページとヘッダー・フッター

- 芦屋堂の `site.json` の `pages`（`pg_home`・`pg_menu`・`pg_contact`）と `regions`（ヘッダー・フッター）を、試験台の作り（塊で組む・部品 ID）で組み直す。見た目は芦屋堂の書き出し（`npm run build`）に近づける。細かい再現は求めない（崩れない配置・編集の動きを確かめるのが目的）
- **ヘッダー・フッターは全ページ共通**（DATA_SPEC 4.1 `regions`）。どのページで直しても、全ページで同じに変わる。動かせない・消せないセクション（記録 12.8）として扱う。中の部品（ロゴ・文字）は今の部品と同じく動かせる・直せる
- 部品 ID はサイト全体で一意にする（ページごとに頭を付ける。例：`M_…`（MENU）・`C_…`（CONTACT）・`H_…`（ヘッダー）・`Ft_…`（フッター））

### 2.2 ページを移る

- **ナビの文字を押すと、そのページに移る**（PowerPoint のスライドを選ぶのと同じく、移るのは編集の中。よそへは飛ばない）。押して離した位置が動いていなければ移る。押したまま動かせばナビの部品が動く（今の部品と同じ）
- 移ったら：ページの一番上を出す。選択は外す。端末（PC・スマホ）はそのまま。書き換え中・見せる範囲の最中なら、先にふつうに終えてから移る（記録 8.19）
- ナビの文字の右クリック：「ページの名前を変える」（ナビとページの見出しに出る名前。② のページの設定）。ほかは今の部品と同じ（ナビの文字はページの名前から自動で作るので、ダブルクリックでの書き換えはしない）
- ナビに出ないページ（プライバシーポリシー・見つからないとき）は、この試験台では作らない
- **「戻す」はサイト全体で1本**（PowerPoint のファイル全体と同じ）。別のページで直したことを戻すときは、そのページに移ってから戻す（移った先で、戻した部品を選んだ状態にする）
- 文の一部・写真・部品まるごとのリンクで「このサイトのページ」を選んでいるもの（記録 8.14）：リンクの札の「開いて確かめる」で、そのページに移る
- **「このページを元に戻す」・「元の配置を見る」は今のページだけ**に効く
- **セクションの追加・複製・削除・並べ替えはページごと**（ページの中のセクションの並び）。セクションの型の一覧（特集・品）はどのページでも同じ
- **スマホでの編集**：ヘッダーのナビをタップして移る（芦屋堂のスマホのヘッダーがメニューのボタンで開く形なら、本物と同じく開いてから押す）

### 2.3 下書きの形（ページごとのセクションの並び）

- 下書きの `sections` を、ページ ID → セクションの並び、にする：`sections: {pg_home: [...], pg_menu: [...], pg_contact: [...]}`
- 開くとき、`sections` が配列（試験台27 までの形）なら、`pg_home` の並びとして読む
- `content`・`adjust`・`added`・`removed`・`textStyle`・`seq` は今のまま（部品 ID がサイト全体で一意なので、ページで分けない）
- セクション ID（`sec1`…）・足した部品の ID はサイト全体で増える一方（今のまま）
- 公開した版・戻す前の下書き・状態の文字（記録 15.2）・公開前の確認（15.4）・プレビュー（15.5）・履歴（15.6）は**サイト全体**で扱う
  - 公開前の確認は、全ページ × PC・スマホで調べる。「見る」は、そのページ・端末に移って部品を選ぶ。説明の頭にページの名前を付ける（例「お品書き・PC：…」）
  - プレビューでも、ナビを押せばページを移る（お客さんと同じ）
- DATA_SPEC は Claude.ai が後で直す（v4.4）。報告に、下書きの見本（3ページとも何か直したもの）を `playground28/draft_sample.json` として置く

### 2.4 お品書きのページ（MENU）

芦屋堂の `pg_menu`：ページの見出し、店頭販売の表、甘味処の見出し・提供時間・表。

- 店頭販売・甘味処とも、**全部を並べる所**（DATA_SPEC 4.6）。足す・複製・消す・書き換えるは、決定済みの 4.6 どおり ① が変わる（トップの表 `I_table` と同じ動き）
- **括りの見出し**を出す（店頭販売は 上生菓子・餅菓子・焼き菓子・干菓子。芦屋堂の書き出しに括りの見出しが無ければ、表の中の小見出しの行として足す）。括りの見出しの文字を書き換えると ① の括りの名前が変わる。右クリック：「括りを足す（この下に）」「括りを消す」（品が残っているときは灰色）
- **品の順番**（記録 2.15 をここで決める。ユーザー決定「PowerPoint 踏襲」）：品の1件（表の1行・品の並びの1件）を**ドラッグして、ほかの品の間に落とすと順番が変わる**（PowerPoint のスライドの一覧で並べ替えるのと同じ）。落とす所に横線（表）・縦線（品の並び）を出す。ほかの括りの間に落とせば、その括りに移る（① の載せ方の括りと順番が変わる）。順番は中身なので両端末に効く。絞り込んだ並び（トップのおすすめ）で動かしたら、`pick` の順番になる（4.6 の「触った並びだけ」）
  - 記録 2.10「1件は位置を動かせない」は、**並べ替えだけできる**に変わる。1件を自由な位置に置くことはできない（今のまま）
- **今は出ていない品**（DATA_SPEC 3.4 で出ない品：時期の外の桜餅、休止中のあんみつ）：**編集のときだけ**、その品の順番の所に薄く出し（不透明度 0.45 くらい）、名前の右に小さく理由を添える（「2〜4月だけ出ます」「休んでいます」）。写真のない枠と同じく、プレビュー・公開・公開前の確認では出さない（詰める）。選ぶ・書き換える・下の 2.5 の道具は、ほかの品と同じにできる
- 甘味処の**提供時間**の文字（トップの `I_time` も）：① のメニューの提供時間（3.2 の時間帯の形）に連動させる。書き換えは 2.6 の箱で

### 2.5 品を選んだときの道具（出す月・販売・ラベル・載せるメニュー）

品の1件（または1件の中の部品）を選ぶと、上の並びの選んだ物の道具に次の4つを出す。出し方は「明るさ ▾」「列 ▾」と同じ（押すと下に一覧。外・Esc で閉じる）。窓が狭いときのしまい方は記録 13.3 のまま（道具の右から）。

| 道具 | 一覧の中身 | ① で変わる所 |
|---|---|---|
| 販売 ▾ | 販売中／休んでいる／終わり（1つ選ぶ） | 品の `status` |
| 出す月 ▾ | 1〜12月のボタン（いくつでも）と「いつでも」。何も選ばない＝いつでも | 品の `season.months` |
| ラベル ▾ | お店のラベルのチェック（おすすめ・数量限定・手土産に…）と「＋ 新しいラベル」 | 品の `labels`・① の `labels` |
| メニュー ▾ | 載せるメニューのチェック（店頭販売・甘味処）。チェックを付けると、そのメニューの一番近い括りの最後に載る。外すと、そのメニューから外す（最後の1つは外せない＝灰色） | ① の載せ方 |

- どれも「戻す」1回で戻る
- 販売・出す月を変えて、その品が今は出なくなったら、その場で薄くなる（2.4）。出るようになったら、ふつうに戻る
- スマホでの編集：品の長押しの箱に「販売」「出す月」「ラベル」「メニュー」→ 下からの板に同じ中身

### 2.6 お店の情報の文字（営業時間・住所・電話など）

芦屋堂の CONTACT・フッター・トップで、① に連動している文字（DATA_SPEC 4.4 の「連動している文字」）を、サイトの上で直せるようにする。

| ① の値 | 直し方 |
|---|---|
| 店名・電話・メール・Instagram・郵便番号・駐車場の補足など、**そのままの文字で出る値** | ダブルクリックして書き換える（品の名前と同じ）。書き換えると ① が変わり、同じ値を出している所はすべて変わる。電話は表示用と発信用を両方作る（DATA_SPEC 2.4） |
| 営業時間・定休日・お休みの期間・提供時間・住所・行き方・支払い方法など、**決まった書き方で組み立てて出す値**（`format` を持つもの） | 選ぶと、選んだ物の道具に「**営業時間を直す**」（値によって「住所を直す」「行き方を直す」「支払い方法を直す」）を出す。**ダブルクリックでも開く**。押すと、その文字のすぐ下に箱が開く（PowerPoint のグラフの「データの編集」と同じく、その場で開いて、直すとサイトの文字が変わる） |

- **営業時間の箱**の中身（DATA_SPEC 3.2）：曜日ごと（営業／休み／予約のみ・時間帯。「＋ 時間帯を足す」）、祝日の扱い（曜日どおり／休み／祝日だけの時間）、曜日の表のほかのお休み（第◯◯曜日・最後の◯曜日・不定休）、お休みの期間（名前・いつから・いつまで・毎年かその年だけ・休みか別の時間か）、ひとこと
  - 見た目は Claude.ai の絵（Artifact「お店の情報の画面（試験台28 案）」の ② の左側）を参考にしてよい。ただし別の画面ではなく、**その場に開く箱**にする（幅 520 くらい。画面に入らなければ画面の中に収める。スマホでは下からの板）
  - 直すそばからサイトの文字が変わる。箱を閉じる：外を押す・Esc・「閉じる」。**箱の中で直したことは、箱を閉じたときに「戻す」1回にまとめる**（PowerPoint の「データの編集」を閉じた後の「元に戻す」と同じく、まとめて戻る）
- **住所の箱**：郵便番号・都道府県〜建物名・「番地を出さない」（DATA_SPEC 7章 Q5）
- **行き方の箱**：駅・歩き／車など・分・ひとこと の行（足す・消す・順番）
- **支払い方法の箱**：現金（使える／使えない）、カード・電子マネー・QR の選択肢のチェック
- どの箱も、書き方（`format`）は今の書き出しの仕組み（`tools/lib/format.mjs`）の書き方に合わせて文字を作る（試験台の中に写して使ってよい）
- 連動を外す（DATA_SPEC 4.4 の「この場所だけ別の文章にする」）は、今回は作らない

### 2.7 品を消すとき

- 確かめの画面は出さない（PowerPoint と同じ。記録 12.7 のセクションの削除とも同じ）。消すと、画面の下に「『わらび餅』を消しました（店頭販売・甘味処の両方から）」と、「戻す」のボタンを 5 秒出す（ほかのメニューにも載っていて、そこからも消えるときだけ、括弧の中を出す）。「戻す」は上の並びの「戻す」と同じ1回
- 全部を並べる所での削除＝そのメニューから外す（4.6）。ほかのメニューに載っていなければ品も ① から消える。知らせの文はそれに合わせる（「お品書きから消しました」）
