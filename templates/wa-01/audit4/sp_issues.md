# 精査4回目（スマホ・指／保存・読み込み直し・公開）editor_f70748a.html

環境：python3 playwright chromium。スマホ＝viewport 390x844・DSF3・is_mobile・has_touch・iPhone Safari の UA。iPad＝820x1180（一部 1180x820）、横向きスマホ＝844x390。
指の操作は CDP `Input.dispatchTouchEvent`（タップ 60ms、長押し 650ms、ドラッグは 16〜30ms 刻み）。文字は `keyboard.insert_text`。
座標は画面（viewport）の CSS px。「文書 y」は scrollY を足した値。スクリプトは /tmp/claude-0/-home-claude/2cf7097e-0eca-5df4-ab26-0927a5409932/scratchpad/audit4/scripts/ にある（s番号は下に書いた）。
注：persistent context（ディスクに書くブラウザの保存先）では、この環境の IndexedDB が開けず（`Internal error opening backing store`）、保存はいつも「保存できませんでした」になる。環境のせいなので問題には入れず、保存の確認は普通の context（メモリ）で、同じ context 内の読み込み直し・別タブで行った。
