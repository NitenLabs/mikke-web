## 2. 写真を変える

### 2.1 写真がある枠：「写真を変える」

- 写真（品の写真も含む）を**1つだけ**選んでいるとき、写真の**真ん中**に「写真を変える」のボタンを出す（カメラの印＋文字。白の丸い角のボタン、文字 14px、高さ 36 以上）。要素に `data-photo-change` を付ける
- 写真の一部しか画面に見えていないときは、**見えている部分の真ん中**に出す。写真が小さくてボタンが入らない（幅がボタンの幅＋16 より狭い、または高さが 52 より低い）ときは、写真のすぐ下の外側に出す
- ボタンを押して、そのまま離す（クリックとドラッグを分ける今の決まりのとおり、動かしていない）→ 写真を選ぶ画面を開き、選んだ写真に差し替える。差し替えの決まりは今のまま（9.2〜9.4）
- ボタンを押したまま動かす → **写真を動かす**（写真をつかんだのと同じ）。写真を選ぶ画面は開かない
- 出さないとき：見せる範囲の中・動かしている最中・大きさを変えている最中・いくつかを選んでいるとき・写真を外した枠
- 右クリックの「写真を差し替える」は残す（慣れた人のため）

### 2.2 写真がない枠：「写真を選ぶ」

- 写真を外した枠と、まだない写真の枠（`missing`）には、**選んでいなくても**、枠の真ん中に「写真を選ぶ」のボタンと、その下に小さく「または、ここに写真を落とす」を出す。今の「ここに写真を入れてください」の文字は出さない。要素に `data-photo-choose` を付ける
- 枠の**どこを押しても**、そのまま離せば、写真を選ぶ画面を開く（枠も選んだ状態にする）。選んだ写真が入る
- 枠を押したまま動かす → 枠を動かす（今のまま）
- 枠に写真のファイルを落とす → 入る（今のまま）
- 公開の見え方では、今のまま（まだない写真は詰める）

## 3. 写真を足す（PowerPoint の「挿入 → 画像」に合わせる）

### 3.1 「写真」のボタン

- 上の道具の並びの「テキスト」のすぐ右に「写真」のボタンを足す（`id="tPhoto"`）
- 押すと、写真を選ぶ画面を開く。選んだ写真を、新しい部品として**いま見えている範囲の真ん中**に置く（上の道具の並びの下から、画面の下端までの真ん中。横はページの中身の真ん中）。写真の真ん中をそこに合わせる。ただし、ページの中身の左右の端からはみ出さないように寄せる
- **ほかの部品は動かさない。重なってもそのまま**。お店の方が自分で置いたものとして扱う（自分で重ねた組。公開前の一覧に出る対象）
- 置いた写真は、置いたらすぐ選んだ状態にする（2.1 の「写真を変える」も出る）。あとはどこへでも動かせる
- 写真を選ぶ画面を取り消したら、何もしない

### 3.2 ファイルを画面に落とす

- 写真の枠（写真がある枠・ない枠、品の写真）の上に落とす → その枠の写真になる（今のまま）
- それ以外の所に落とす → 新しい部品として、**写真の真ん中を、マウスを離した位置に**置く（ページの中身の左右の端からはみ出さないように寄せる）。3.1 と同じく、ほかの部品は動かさず、置いたら選んだ状態にする
- 落とす前に、入る場所の予告（点線の枠など）は出さない。写真の枠の上にいるときの縁取りは今のまま
- いくつかのファイルを一度に落としたら、最初の1枚だけを使う

### 3.3 画像の貼り付け

- ふつうの貼り付け（Cmd+V）で、クリップボードに**画像のファイル**があるとき：
  - 写真を1つだけ選んでいる → その写真の差し替え（今のまま）
  - それ以外 → 3.1 と同じく、見えている範囲の真ん中に新しい部品として置く
- クリップボードに画像がないときは、今の貼り付け（部品・文字）のまま
- 書き換え中の貼り付けは今のまま（文字だけ）

### 3.4 足した写真の決まり

- 部品の ID は、今の「足した部品」と同じ付け方（新しい ID、使い回さない）
- 大きさ：幅は、**PC の配置では中身の幅の半分**（小数は切り捨て）、**スマホの配置では中身の幅いっぱい**。高さは写真の縦横の比のまま。ただし**高さが幅の 1.25 倍を超えるときは、枠を 4:5 にして、写真の真ん中を見せる**。写真は今の決まりどおり長い辺 2400px まで縮め、向きの情報どおりに直す
- **置いた端末**：置いた位置を、手で置いた位置（手直し）として記録する。付いていく先は、手で動かして離したときと同じ選び方（4.1〜4.5）で取る。セクションは、写真の真ん中があるセクション
- **もう一方の端末**：貼り付けた部品がもう一方の端末に入る決まり（11.4）と同じ。コピー元の代わりに、**置いた端末で付いていく先になった部品**のすぐ下（間隔 16）に入れ、左端をその部品にそろえ、中身の幅以内に収める。この自動の位置は手直しとして扱わない
- 品の1件・表の行の中の部品にはしない（その上に重なって置かれる、セクションの部品）
- 足した写真は、ふつうの写真と同じに扱う（写真を変える・見せる範囲・写真を外す・明るさ・消す・コピー・複製・前面へ／背面へ）。消すと両端末から消える
- 「元の位置に戻す」「このページを元に戻す」では、足した写真は**残り**、位置だけが「もう一方の端末」と同じ自動の位置（付いていく先のすぐ下）に戻る
- 1回の追加（3.1〜3.3 のどれでも）は、「戻す」1回でなかったことになる

## 4. 「テキスト」の入り方をそろえる

- 今の「テキスト」（押してから部品をクリックすると、その部品の下に入る）をやめる。押してから部品を選ぶ待ちの状態もなくす
- 押すと、3.1 と同じく**見えている範囲の真ん中**に、文字の箱（幅は今のまま PC 600・スマホ 351、文字は「テキスト」、見た目は今の足した文字と同じ）を置き、**すぐ書き換えの状態**にして、文字全部を選んだ状態にする（打てば置き換わる）
- ほかの部品は動かさない。重なってもそのまま（自分で置いたもの）
- 置いた端末・もう一方の端末・元に戻すときの決まりは 3.4 と同じ（幅は文字の箱の幅）
- **書き換えを終えたとき文字が空なら、その箱は消し、足したこと自体をなかったことにする**（「戻す」の履歴にも残さない。PowerPoint の空のテキストボックスと同じ）
- スマホでの編集の「その他」→「テキストを足す」は、今回変えない

## 5. 明るさ（PowerPoint の「修整」に合わせる）

### 5.1 やり方

- 写真（品の写真・足した写真も含む）を**1つだけ**選んでいるとき、上の道具の並びの右に「明るさ ▾」を出す（文字を選んだときに文字の道具が出るのと同じ場所の考え方）。`data-photo-tool="brightness"` を付ける
- 写真を外した枠・まだない写真の枠・いくつかを選んでいるとき・文字や他の部品を選んでいるとき・何も選んでいないときは出さない
- 押すと、そのすぐ下に一覧を開く。**その写真で作った見本を5つ**横に並べる：−40%・−20%・元のまま・+20%・+40%（見本の下に「−40%」「−20%」「元のまま」「+20%」「+40%」）。各見本に `data-bright="-40"` などを付ける。いまの値の見本を縁取る
- 見本にマウスを乗せている間は、**ページの写真をその明るさで仮に見せる**（記録しない）。見本から外れたら、いまの値の見え方に戻す
- 見本を押す → その明るさに決め、一覧を閉じる。「戻す」1回で前の値に戻る
- Esc・一覧の外を押す → 何も変えずに閉じる

### 5.2 決まり

- 明るさは、−40〜+40 の 20 刻みの数として、**写真の枠ごとの中身**として持つ（品の写真なら、その1件だけ）
- **PC とスマホで共通**
- 「このページを元に戻す」「元の位置に戻す」では**戻さない**（中身の扱い）
- **写真を変えたら（差し替え・空の枠に入れた）0 に戻す**。写真を外して戻したときは、外す前の値に戻す
- 見え方は、写真に `filter: brightness(1 + 値/100)` を掛ける。編集の見え方でも公開の見え方でも同じ。見せる範囲の中でも掛かったまま
