## 1. 新しい C のルール

### 1.1 考え方

前回の C は、手で動かした部品の下にある部品も一緒に動いた。そのため「見出しだけ少しずらしたい」ときに本文まで動き、扱いにくい。そこで、手で動かすときと、中身が変わるときでルールを分ける。

- **手で動かしたとき（PowerPoint と同じ）**：選んだ部品だけが、ドラッグした分だけ動く。選んでいない部品は、見た目の位置が変わらない。
- **動かし終わったとき**：動かした部品と、それまで動かした部品に付いていた部品について、今の見た目のまま「どの部品の下に、どれだけ空けて置かれているか」を取り直す。付いていく先は、すぐ上にあって横の範囲が重なる部品にする（なければセクションの見出しの組）。
- **中身が変わったとき（Word と同じ）**：取り直した関係に従って付いていく。テンプレートどおりの部品は、今までどおり塊の中で押し出され、詰められる。

### 1.2 守るべきこと

| # | 内容 | 許容差 |
|---|---|---|
| H1 | 動かした部品は、指やマウスを離した位置にぴったり止まる（塊の縦中央そろえの中にある部品も同じ） | ±0.5 |
| H2 | 選んでいない部品は、動かした直後に見た目の位置が変わらない | ±0.5 |
| H3 | 動かした後に中身を変えると、動かした部品は取り直した付いていく先に従って動く | 付録の試験で確認 |
| H4 | 手動の記録（`overrides`）が付くのは、オーナーが動かした部品と足した部品だけ | ― |

H2 と H4 を同時に満たすために、動かしていない部品にも記録を付ける必要が出た場合は、そのやり方と理由を報告する（勝手に進めない）。

## 2. まとめて選ぶ

- **PC**：何もない所から範囲をドラッグして囲むと、枠の中に**全体が入った**部品が選ばれる。Shift を押しながらクリックすると、選ぶものを足したり外したりできる
- **スマホ**：「まとめて選ぶ」ボタンを押している間は、押した部品が選ぶものに足されていく
- 選んだ部品をドラッグすると、全部が同じ距離だけ動く（H1・H2 は、選んだもの全体と、選んでいないものについて守る）
- 品・FAQ のような繰り返す部品は、1件ずつは選べない（優先の規則4）

---

## 3. 付いていく先を見せる

- ドラッグしている最中に、離したら付いていく先になる部品を青い枠で光らせ、その部品の下端から動かしている部品の上端まで、青い点線を引く。近くに「○○の下に付いていきます」と表示する
- まとめて動かしているときは、動かしている部品それぞれについて表示する
- ドラッグしていなくても、手で動かした部品や足した部品を選んだときは、付いていく先と点線を表示する
- 部品の名前は、オーナーが分かる言葉で書く（例：「特集1の写真」「区切り線」）

## 5. 試験

### 5.1 比較の試験（テンプレートの動きが変わっていないことの確認）

新しい C に、G1〜G3・付録 B（S1〜S7）をすべてかける。テンプレートの部品の動きは前回の C と同じはずなので、前回の C と ±0.5 で一致することを確かめる。

### 5.2 手で動かす試験（新しい C と A の両方にかける）

操作は、ページの `__playground` から**本物のマウスの操作**（押す・動かす・離す）で与える。すべて PC とスマホの両方で行う。

| # | 操作 | その後の中身の変化 | 確かめること |
|---|---|---|---|
| P1 | 特集1の見出しだけを、右へ12・下へ8動かす | S1（本文を3行増やす） | 動かした直後に H1・H2。S1 の後の見出しと本文の位置、重なりと警告 |
| P2 | 特集1の見出しと本文を範囲で囲んで選び、下へ40動かす | S1 | 動かした直後に、2つとも 40 動く（H1）。写真は動かない（H2）。S1 の後の位置 |
| P3 | 特集1の本文を、写真の下（写真と左端をそろえ、下端から24）へ動かす | S1、次に S2（見出しを2行に） | 動かした直後に H1・H2（見出しが動かない）。S1・S2 の後、本文が写真に付いているか |
| P4 | 区切り線の下 24 に文字を足す | S4（品を4件に） | 足した文字が区切り線と一緒に下がるか（C）、残るか（A）。重なりと警告 |
| P5 | 特集1の写真を、左へ60・下へ40動かす | S1 | H1・H2。S1 の後の写真と文字の位置 |
| P6 | 特集2の写真を消す（E5）／外す（E5b） | なし | 前回と同じ結果 |
| P7 | P1 の後、テンプレートの見出しと本文の間隔を 16→24 に変える（E8） | なし | 見出しと本文の距離、手動の記録の中身 |
| P8 | PC で P1 を行う | なし | スマホの全部品が変わらない（±0.5） |
| P9 | ドラッグで動かせるすべての部品を、PC とスマホでそれぞれ3回、別々の方向へ動かす | なし | 毎回 H1・H2 |
| P10 | P1〜P5 のそれぞれの後に「1つ戻す」を押す | なし | 動かす前の位置に戻る（±0.5） |

P1・P3・P5 の「S1 の後」は、どうなるべきかを決めていない。数値と画像を出し、ユーザーが自然かどうかを判断する。

### 5.3 付いていく先の記録

`__playground` に `anchors()` を足す。手で動かした部品と足した部品について、付いていく先の部品と間隔の一覧を返す。P1〜P5 の各操作の後の結果を報告に載せる。
