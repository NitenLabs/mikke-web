## 2. 縦積みの間隔の決まり（N1・N3）

縦積みの塊の中の、隣どうしの部品の間隔は、**テンプレートと今の並び順だけから決める**。手直しとして数字を持たない（DATA_SPEC の並び順は「何の後ろ」で持つ、と合う）。

| 場合 | 間隔 |
|---|---|
| テンプレートで元々隣どうしだった2つ（上下が入れ替わっていても） | テンプレートのその2つの間隔のまま |
| 初めて隣になった2つ（A の下に B） | 「A のテンプレートでの下の間隔」と「B のテンプレートでの上の間隔」の**広い方** |
| 塊の一番上・一番下の部品で、上（下）の隣がテンプレートにない | その側の間隔は 0 とみなし、もう一方で決まる |

- 「下の間隔」「上の間隔」は、その端末のテンプレートの配置で、その部品とテンプレートでの次（前）の部品との間
- 並び替えたとき、部品が塊の外へ出たとき（M2）、戻したとき、のすべてに使う
- 端末ごとに、その端末のテンプレートの間隔で計算する
- 今の特集の縦積み（スマホ）と、品の縦積みで見出し・営業時間・表が抜けるときは、すでにこのとおりになっている（Claude.ai の確認で合格）。変えるのは区切り線が抜けるときと、並び替えたとき

品のセクションの例（Claude.ai の環境での値。書体が違うので、Claude Code では少し違ってよい。見るのは決まりどおりかどうか）：

|---|---|---|---|---|---|---|---|---|---|---|---|
| テンプレート（PC） | | 120 | | 120 | | 4 | | 13 | | 64 | |
| テンプレート（スマホ） | | 98 | | 64 | | 5 | | 13 | | 48 | |

- 区切り線が抜けた後（N1）：品の並び ─120／98─ 見出し ─4／5─ 営業時間 ─13─ 表 ─64／48─ ボタン
- R2（区切り線を見出しと営業時間の間へ）：品の並び ─120／98─ 見出し ─120／64─ 区切り線 ─120／64─ 営業時間 ─13─ 表 ─64／48─ ボタン（営業時間から下は押し下げられる）
- T2（区切り線を表とボタンの間へ）：品の並び ─120／98─ 見出し ─4／5─ 営業時間 ─13─ 表 ─120／98─ 区切り線 ─120／64─ ボタン

## 3. 並び替えか M2 か（N2）

並び替えの相手は、部品が元々属するテンプレートの縦積みの塊の**直接の子すべて**（品のセクションなら、品の並び・区切り線・甘味処の見出し・営業時間・表・ボタン）。離した位置（ドラッグ中の部品の縦の中心）で、次のように決める。

| 離した位置 | 結果 |
|---|---|
| 直接の子と子の間の空き | その間に並び替え |
| 1件ずつ繰り返す部品を中に持つ子（品の並び・表）の箱の中 | M2（付いていく先はその子。前の作業票の 2.2 のとおり） |
| それ以外の子（見出し・営業時間・区切り線・ボタン）の箱の中 | その子の縦の中心より上なら上へ、下なら下へ並び替え |
| 部品が元々属する塊の外 | M2（前の作業票のとおり） |

- 前の作業票の3章の「40px の内側」でずらしただけなら、これまでどおり M1（R1・R8）
- 足した部品（貼り付け・複製）は、縦積みの子ではないので並び替えない。これまでどおり M2（R9）
- 特集の縦積み（R6・R7）は、繰り返す部品を中に持つ子がないので、これまでどおり
