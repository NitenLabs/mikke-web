## 2. 作ること

### 2.1 配置（揃え・整列）

PowerPoint の「ホーム → 配置 → 配置 ▸」と同じ8つ。

| 名前 | 1つ選んでいるとき | 2つ以上選んでいるとき |
|---|---|---|
| 左揃え | セクションの中身の左端に | 一番左の部品の左端に |
| 左右中央揃え | セクションの中身の真ん中に | 選んだ全体の左右の真ん中に |
| 右揃え | セクションの中身の右端に | 一番右の部品の右端に |
| 上揃え | セクションの上端に | 一番上の部品の上端に |
| 上下中央揃え | セクションの上下の真ん中に | 選んだ全体の上下の真ん中に |
| 下揃え | セクションの下端に | 一番下の部品の下端に |
| 左右に整列 | 灰色 | **3つ以上**で押せる。左端と右端の部品は動かさず、間の部品を、隣どうしの空きが同じになるように並べる（左右の順は今の順のまま） |
| 上下に整列 | 灰色 | 同じく上下 |

- PowerPoint の「スライドに合わせて配置／選択したオブジェクトを揃える」の切り替えは、上の表のとおり**選んだ数で決める**（PowerPoint の既定と同じ）。切り替えのボタンは出さない
- **入口**：
  - PC：部品を選んでいるとき、上の並びの選んだ物の道具に「**配置 ▾**」（記録 13.2 の並び。窓が狭いときにしまう順は、道具の右から＝今の決まりのまま）。押すと8つの一覧。アイコンと名前（PowerPoint と同じ見た目の絵）。押せないものは灰色
  - スマホでの編集：部品の長押しの箱に「配置」→ 8つの一覧（下からの板）
  - 右クリックのメニューには入れない（PowerPoint も右クリックには無い）
- **対象にできる部品**：動かせる部品（文字・写真・区切り線・ボタン・足した部品）と、表・品の並びの全体。品の1件・表の1行の中の部品（記録 2.10）、動かせないセクションの決まりの部品は対象外。対象外を含む・ちがうセクションの部品を一緒に選んでいるときは、「配置 ▾」を灰色にする
- **動いた後の扱い**：それぞれの部品を、**その位置まで Alt を押しながらドラッグして離したのと同じ**に扱う（吸い付きなし。記録 2.5 の M1／M2 の判定、付いていく先の取り直し、元の場所を詰める）。ただし**間の帯での並び替え（記録 2.6 ②）は起こさない**（揃えたつもりで並びが変わらないように）。重なれば自分で重ねたもの（記録 5.2）
- **「戻す」1回**で、動いた部品すべてが戻る
- 位置は端末ごと（今の端末だけが動く。記録 1.2）

### 2.2 等間隔の目安

PowerPoint のスマートガイドの「間隔がそろった」印と同じ。

- **いつ**：ドラッグで動かしている間（記録 7.1 と同じ。矢印キー・Alt を押しながらのときは出さない・吸い付かない）
- **相手**：記録 7.2 と同じ部品（同じセクションの、動かせる部品・表・品の並びの外枠。品の1件・表の1行の中は相手にしない）
- **横の等間隔**：動かしている部品と上下の範囲が重なる部品を「同じ行」とみなす。次のどれかになる位置の近く（画面上で 6px 以内、スマホは 10 以内）なら吸い付く
  1. 動かしている部品と隣の部品の空き ＝ その隣の部品とさらに隣の部品の空き（右側・左側どちらにも）
  2. 動かしている部品が2つの部品の間にあり、左右の空きが同じ
- 縦も同じ（左右の範囲が重なる部品を「同じ列」とみなす）
- **印**：そろった空きのそれぞれに、両端に短い縦線（縦の等間隔なら横線）の付いた矢印の線を出す。色は今の目安の線と同じ。離したら消す
- **ぶつかったとき**：同じ向き（横なら横）で、そろえる線（記録 7.2）と等間隔の両方が近ければ、近い方。同じ近さならそろえる線。縦の向きで並び替えになるとき（記録 7.4）は、並び替えが勝つ
- 大きさを変えている間の「同じ大きさ」の目安は、今回は作らない

### 2.3 Esc で選択を外す

- 文字を書き換えていない・写真の見せる範囲を直していない・メニューや箱が開いていないときに Esc を押したら、選んでいる部品・セクションの選択をすべて外す（PowerPoint と同じ）
- メニュー・箱が開いているときの Esc は、今までどおりそれを閉じるだけ（選択は外さない）。書き換え中・見せる範囲の最中の Esc も今までどおり
- 日本語の変換中の Esc はページが拾わない（記録 8.18 のまま）
