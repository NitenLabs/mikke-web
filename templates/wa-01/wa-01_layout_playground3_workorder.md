## 1. 動かすときのルール（抜け殻の直し）

前回、次の2つが起きた。

- P1：見出しだけ動かした後で本文を増やすと、見出しの付いていく先が 259px 上の「特集の見出しの組」になり、塊が中央にそろえ直されたときに、見出しと本文が重なった

そこで、動かした先によって扱いを分ける。

| # | 動かした先 | 扱い |
|---|---|---|
| M1 | **同じ塊の中**（離したときの部品の中心が、その部品が属する塊の範囲の中） | テンプレートが計算した元の位置からの「ずれ」として持つ。塊が動けば一緒に動く。選んでいない部品は動かない |
| M2 | **塊の外** | 元の場所を詰める（元の塊の残りの部品が詰め直される）。移した先では、すぐ上にあって横の範囲が重なる部品に付いていく |
| M3 | **まとめて動かしたとき** | 部品ごとに M1・M2 を判断する。M2 になった部品どうしは、上にあるほうに下のほうが付いていく（まとめて動かした組は、その後も一緒に動く） |

- M2 では、ドラッグの最中に「ここが詰まります」を見せる（元の場所を淡く示し、詰まった後の周りの位置を薄く重ねて表示する）

## 2. その場で書き換える

- PC はダブルクリック、スマホは選んだ文字をもう一度押すと、その場で書き換えられる。文字の外を押すか、Esc で終わる
- 改行できる（Enter）
- 打つそばから配置を計算し直し、下の部品が押し出されたり詰まったりする様子がすぐに見える（遅れは 100ms 以内）
- 書き換えた中身は PC とスマホで共通（位置は端末ごと、中身は共通）
- 品の名前・説明・値段も書き換えられる（動かせないのは品の位置だけ）
- 書き換えている間は、改行の規則（BudouX・最終行の規則）を当てずにそのまま表示し、終わったら当てる

### 2.1 日本語入力

- **変換の途中（`compositionstart` から `compositionend` まで）は、配置の計算も画面の組み直しもしない**。変換が確定したら計算する
- 書き換え中の部品の DOM を作り直さない（作り直すと、入力の位置と変換が壊れる）

## 3. 操作の出し方（左の箱をなくす）

- 左の操作の箱をなくす
- 部品を選ぶと、その近くに小さな操作ボタンが浮かぶ。右クリックでも同じものが出る

| 選んだもの | 出すボタン |
|---|---|
| 文字 | 書き換える／元の位置に戻す（手で動かしたときだけ）／消す |
| 写真 | 写真を外す・戻す／元の位置に戻す（手で動かしたときだけ）／消す |
| いくつか | 元の位置に戻す／消す |
| 品 | 書き換える（位置は動かせないことを一言で添える） |

- 上の端に細いツールバーを置く：テキスト（押してから置きたい場所をクリックするか、ドラッグで枠を描くと、すぐ書き換えの状態になる）／PC・スマホの切り替え／元の配置を見る／このページを元に戻す／戻す・やり直す
- 試験の再現ボタン（Q1〜Q8）と操作の記録は、ツールバーの端の「制作用」を押したときだけ出す
- 付いていく先の青い線と言葉は、前回のまま

## 4. 元に戻す

| 単位 | 出し方 | 戻るもの |
|---|---|---|
| 部品 | 部品の近くの操作ボタン | その部品の、今の端末での位置と大きさ |
| セクション | セクションを選んだとき（セクションの余白を押す）に出るボタン | そのセクションの、今の端末での全部品の位置と大きさ（足した部品は消えない） |
| ページ全体 | ツールバー | 今の端末での全部品の位置と大きさ。「両方の端末」も選べる |

- **戻るのは位置と大きさだけ**。書き換えた文字、外した写真、足した部品、消した部品はそのまま
- 「元の位置」は、テンプレートが**今の中身から**計算した位置
- 手で動かした部品には小さな印を付ける
- 「元の配置を見る」：押している間だけ、手で動かした部品が元の位置に表示される。離すと戻る。記録には何も残らない
- 戻したことも、Cmd+Z で取り消せる

## 5. キーボード

- Cmd+Z で戻す、Cmd+Shift+Z でやり直す（Windows は Ctrl）
- 矢印キーで選んだ部品を 1px、Shift を押しながらなら 10px 動かす（M1 として扱う）
- Delete・Backspace で選んだ部品を消す
- 書き換えている間のキーは文字の入力に使い、上の操作はしない（書き換え中の Cmd+Z は文字の取り消し）

### 5.1 コピー・切り取り・貼り付け・複製

| キー | 部品を選んでいるとき | 書き換えている間 |
|---|---|---|
| Cmd+C | 選んだ部品をコピーする | 選んだ文字をコピーする |
| Cmd+X | コピーして、部品を消す | 選んだ文字を切り取る |
| Cmd+V | 貼り付ける（下の表） | 文字を貼り付ける。**書式は捨てて文字だけにする**（Word や他のサイトから貼っても、フォントや色が持ち込まれない） |
| Cmd+D | 選んだ部品を複製する（コピーと貼り付けを一度に） | ― |

貼り付けたときの置き場所と扱い：

| コピーしたもの | 貼り付けた結果 |
|---|---|
| 文字・写真（テンプレートの部品でも、足した部品でも） | **足した部品**として新しく作る。元の部品の右へ16・下へ16ずらした位置に置き、M2 と同じく、すぐ上の部品に付いていく。セクションを選んでいるときは、そのセクションの中に置く |
| 品（繰り返す部品の1件） | **品が1件増える**。コピーした品のすぐ後ろに入り、以下は並び直す（位置を手で持たない。優先の規則4） |
| いくつかの部品 | 全部を、互いの位置関係を保ったまま同じだけずらして貼る（M3 と同じく、上の部品に下の部品が付いていく） |

- 写真の画像そのもの（スクリーンショットなど）を貼り付けて写真を差し替える機能は、今回は入れない（写真の差し替えの作業でまとめて行う）
- 貼り付けも複製も、Cmd+Z で取り消せる

### 5.2 足した部品は両方の端末に出す

文字を足したとき、貼り付け・複製をしたときは、**PC とスマホの両方に**その部品を作る（中身は共通のため）。

- 操作した端末では、置いた位置に置く
- もう一方の端末では、同じ部品に付いていき、間隔は同じ値にする。横の位置は、付いていく先の左端にそろえる
- もう一方の端末で置かれた位置は、手で動かしたものとして扱わない（印を付けない）。そちらで動かしたときに初めて、その端末の手動になる
- 消すときは、両方の端末から消す

## 7. ページと確かめるための入口

- 渡す用のファイル：`refs/compare/layout/playground3_single.html`（前の作業票の 2.1 の条件どおり、1つのファイル）
- `window.__playground` に次を置く。**名前はこのとおりにする**

| 関数 | 中身 |
|---|---|
| `reset()` | すべての操作を消す |
| `setDevice('pc'｜'sp')` | 端末の切り替え |
| `geometry()` | 表示中のすべての部品の、セクションの上端・左端からの x・y・幅・高さ（縮小前）。部品の ID ごと |
| `sections()` | 各セクションの上端と高さ |
| `warnings()` | 警告の一覧 |
| `anchors()` | 手で動かした部品と足した部品の、付いていく先と間隔、M1・M2 の別 |
| `ops()` | 操作の並び（各操作に端末を含める） |
| `presets()` | Q1〜Q8 の操作の並び |
| `runPreset(name)` | その並びを、本物のマウス・キーボードの操作に近い形で流す。終わったら resolve する Promise を返す |
| `select(ids)` | 部品を選ぶ |
| `edit(id, text)` | 部品の文字を書き換える（書き換えの操作として記録する） |
| `resetScope('part'｜'section'｜'page', id, devices)` | 元に戻す |
| `undo()`・`redo()` | 戻す・やり直す |
| `layoutCount()` | 配置の計算が走った回数（Q5 の確認に使う） |

- 部品の DOM には `data-el` に部品の ID を入れる（前回と同じ）
