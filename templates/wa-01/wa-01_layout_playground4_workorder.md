## 2. つかめる範囲（K1）

- 高さか幅が 16px 未満の部品は、つかめる範囲を、見た目の上下（または左右）にそれぞれ 8px ずつ広げる。見た目の大きさと配置は変えない
- 選んだときの枠も、広げた範囲で表示する

## 3. 塊の外の見分け方（K2）

- 「塊の外」（M2）とみなすのは、次のどちらかのときだけにする
  1. 離したときの部品の中心が、その部品が属する塊の範囲を**上下左右に 40px 広げた範囲**の外にある
  2. 離したときの部品の中心が、**別の塊**の範囲の中にある
- それ以外は M1（元の位置からのずれ）
- ドラッグの最中に M1 と M2 のどちらになるかが分かるように、M2 になる位置に来たときだけ「ここが詰まります」の表示を出す（前の作業票の 1章）

## 4. 付いていく先の選び方（K3・K4）

次の順で選ぶ。

1. **貼り付け・複製した部品は、コピー元に付いていく**（5章）
2. それ以外は、同じセクションの中で、すぐ上にあって横の範囲が重なる部品のうち、**最も近いもの**
3. **繰り返す部品（品・FAQ など）の1件の中の部品は、付いていく先にしない**。その代わりに、繰り返す部品の並び全体（例：「品の並び」）を候補にする
4. 候補がなければ、セクションの見出しの組

- 付いていく先の表示（青い線と言葉）は、前回のまま

## 5. 貼り付け・複製の置き場所（K4・K5・K6）

前の作業票の 5.1 の「元の部品の右へ16・下へ16」をやめ、次にする。

| 項目 | 決まり |
|---|---|
| 置き場所 | コピー元の**すぐ下**（間隔 16）、左端をコピー元にそろえる。コピー元に付いていく |
| いくつかを貼る | 互いの位置関係を保ち、全体をコピー元の組のすぐ下に置く |
| もう一方の端末 | その端末でも、コピー元のすぐ下（間隔 16）、左端をコピー元にそろえる |
| 幅 | 各端末で、コピー元のその端末での幅と同じ。ただし、その端末のセクションの中身の幅を超える場合は、その幅に縮める（写真は縦横比を保って縮める） |
| 大きさ | 写真の複製・貼り付けは、コピー元と同じ幅・高さ（K6） |
| 表示の名前 | 写真は「足した写真」、文字は「足した文字」 |
| 別のセクションに貼る | そのセクションの中身の一番下（間隔 16）に置く |

- 貼り付けた直後に、コピー元にも、ほかの部品にも重ならないこと。重なる場合は、重ならなくなるまで下にずらす（その端末の中で、下の部品を押し下げるのではなく、自分が下がる）

## 6. 縦に並んだ場所での並び替え（K7）

- 部品を、**縦に並んだ塊**（スマホの特集のブロック、PC・スマホの文字の塊など）の中の、ほかの部品と部品の**間**に離したときは、重ねずに、その間に**割り込ませて並び替える**
- 「間」の判定：離した位置が、並んでいる部品の縦の中心を越えたかどうかで決める。ドラッグの最中に、割り込む位置に横線を出す
- 並び替えは、その端末の手動として記録する（性質は「並び順」）。元に戻すと、テンプレートの並び順に戻る
- 並び替えた部品は、ずれ（M1）を持たない。並び替えと同時に元の場所は詰まる
- 横に並んだ塊（PC の写真と文字の横並び）での並び替えは、今回はしない（入れ替えたい場面がはっきりしてから）

## 10. 追記（2026-09-23。**1〜9章より優先する**）

1〜9章と食い違うところは、この章に従う。

### 10.1 並び替えは、同じ塊の中だけ

6章の並び替えを、次のように絞る。

- 並び替えが起きるのは、部品を**自分が属する縦に並んだ塊（すぐ上の親の塊）の中**の、部品と部品の間に離したときだけ
- 自分の塊の**先頭の部品より上**に離した場合も、その離した位置が自分の塊の範囲を 40px 広げた範囲の中なら、「先頭へ並び替え」とする（下の端も同じく「末尾へ並び替え」）
- 別の塊の中の部品と部品の間に離したときは、並び替えではなく M2（3章）にする。別の塊へ割り込ませることはしない
- これにより、K7（スマホで本文を写真と見出しの間へ動かす）は、「本文を文字の塊の先頭へ並び替える」になる。見た目は「写真→本文→見出し」の順になり、重ならない

### 10.2 表の行も「繰り返す部品の1件」に含める

- 甘味処の表の1行と、その中の部品（品名・説明・値段・縦の罫線など）は、品のカードと同じく**繰り返す部品の1件**として扱う
- したがって、1行ずつは動かせず（押したときは「1行の作りを変えると全部に効きます」を出す）、**付いていく先にもしない**
- 付いていく先の候補には、表の全体（「甘味処の表」）を使う（4章の3と同じ扱い）
- 表の行の中の文字の書き換え、行の複製（Cmd+D で1行増える）は、品のカードと同じくできる
