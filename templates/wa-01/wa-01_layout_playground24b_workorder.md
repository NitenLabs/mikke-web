## 2. 直すこと

### 2.1 素の文字・写真を `content[]` に書く（`_pg.secContent` をやめる）

24 の報告 §2.1-1 の理由（開き直す前と後で `content[]` の出方が揺れる）は、**畳み方で解く**。

- fold は、部品ごとに「今の中身」と「テンプレートの初めの中身」を比べ、**違うものだけ**を `content[部品ID]` に書く（DATA_SPEC 4.9「テンプレートと同じ値も書かない」）。`editMap`・`replaceMap` に残っているかどうかでは決めない
  - 文字：見た目のない文字は文字列、見た目のある文字は切れ目の並び（今のまま）
  - 写真：`asset` がテンプレートの写真と違うときだけ書く。`cleared`・`bright`・`link` は今のまま
- 複製・足したセクション（`sec*`）は、その種類のテンプレートの初めの中身（`templateSectionContent(type)`）と比べる。部品 ID は `<セクションID>__<部品ID>`（4.9.3 の ID の決まり）
- seed は `content[]` から文字・写真を戻す
- これで、手で元どおりにした文字や、差し替えてから元の写真に差し替え直したものは、`content[]` から消える（S5 と同じ考え）
- **`_pg` に残すのは、品・表の行の中身と並びだけ**（4.11④が未決のため）。キーの名前は `_pg.rows` など、何が入っているか分かる名前にする。品・表の行の中の文字も、品・表の行の器ごと `_pg` に入れてよい（`content[]` と二重に持たない）

### 2.2 列・見せる範囲・左右の入れ替えを `adjust[端末]` に入れる

24 では `cols`・`view`・`swap` を下書きの直下に置いた。どれも端末ごとの値なので、4.9.1 のとおり `adjust[端末][ID]` に入れる。

- `adjust.pc.I_cards.cols`・`adjust.sp.F_p0.view`・`adjust.pc.<塊のID>.swap: true` の形
- 触っていない端末には書かない
- 「このページを元に戻す」「元の位置に戻す」で消える範囲は 4.9.4 のとおり（今の動きのまま）

### 2.3 足した部品を 4.9 の形にする（`_pg.adds` をやめる）

4.9.3 の `added: {id, kind, from?, placedOn, anchor}` と、置いた端末の `adjust` で持つ。

| 今の `_pg.adds` / `_pg.placedFollow` | 試験台24b |
|---|---|
| `placed`・`gap`・`x`（置いた端末の位置） | `adjust[placedOn][id].place: {after, gap, x}` |
| 置いた端末の `w`・`h` | `adjust[placedOn][id].size` |
| `placedFollow`（もう一方の端末の付いていく先） | 保存しない。開くとき、置いた端末の `place.after` から求める（4.10・8.5・9.7） |
| `placedDevice` | `placedOn` |
| 焼き込んだ文字・写真の `asset` | `content[id]`（2.1 と同じ） |
| `section` | 書かない（`anchor` か `place.after` の部品の属するセクションから求まるなら）。求まらない場合があれば報告 |
| `wOther`・`hOther`・`styleName` | まず**書かずに済むか**を試す（下記）。済まなければ `added` に足して、報告に書く |

- `wOther`・`hOther`：もう一方の端末での幅・高さ。コピー元（`from`）のその端末での今の大きさから求められるか試す。コピー元を後で動かした・大きさを変えた・消した場合に、足した部品の大きさが変わってしまうなら、**求められない**として `added` に `size: {pc?, sp?}`（足したときのもう一方の端末の大きさ）を足す
- `styleName`：`kind` から決まるなら書かない。決まらない（同じ `kind` で違う文字の種類がある）なら `added` に `style` を足す
- 「足した部品は元の位置に戻すと自動の位置になる」（`placedCleared`）は、`adjust[placedOn][id].place` を消すことで表す。別の印が要るなら報告に書く
- `_pg.adds`・`_pg.placedFollow` は無くす

### 2.4 X36：矢印キーで足した部品が動かない

- 今：足した部品（置いた端末で `place` を持つもの）を選んで矢印キーを押しても動かない（24 の報告 §3 の注意。試験台23 以前から）
- 直す：PowerPoint と同じく、**選んでいる部品は何でも矢印キーで動く**。足した部品は `place` の `gap`・`x` を変える（ドラッグで動かしたときと同じ記録の形にする）。1回押すと1回の「戻す」（今のテンプレートの部品と同じ）
- 動く量・Shift との組み合わせは、テンプレートの部品と同じ

### 2.5 `verify_playground.py` の `ONLY` で実行も絞る

- 24 では出力を絞るだけだった。`presets` を読んだ直後に、`ONLY` に書いた名前だけに `presets` を絞る1行を足す（Claude.ai が写しでしていたのと同じ）

```python
if ONLY: presets = {k: v for k, v in presets.items() if k in ONLY} if isinstance(presets, dict) else [k for k in presets if k in ONLY]
```

- 出力を絞る仕組み（`_included`）はやめて、全部出す（Q・R・T・V の試験は区画を絞っても走るので、その結果も見たい）
- `ROUNDTRIP=1` の呼ぶ場所を、`Y1`・`Z1`・`P1`・`U1`・`J1`・`D1`・`C1` の各区画の前と、R3 の前にも足す（今は Q/R の後と最後だけ）
- 編集の動きを確かめている所は触らない
