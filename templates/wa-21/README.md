# wa-21：スパイスカレー 月とバジル の型（G035・lane3）

白い地に深緑の文字、ターメリックの黄と唐辛子の赤を小さく効かせたスパイスカレーの型。写真の後ろにずらした色の影・小さく傾けた写真・水玉の地・段の頭の札で、色鮮やかでも散らからない楽しさを出す。
見せ場は「スパイスの帳面」の段（スパイス 8 種を、色の丸・英字・名前・効きの札・一言で 2 列に並べる。スマホは 1 列）。カレーの段の「使うスパイス」の丸は、この段の色を名前で引く。

- 段の順：最初の画面（店名とコピー＋皿の写真と傾けたスパイスの写真）→ スパイスの帳面 → 今日のカレー（正方形の写真のカード 3 枚）→ あいがけ（淡い生成りの面に値段・トッピングと傾けた写真 2 枚）→ 店のこと（カウンターの写真と大きな淡い英字の帯）→ ご案内（罫線の行・電話のボタン・地図）→ フッター
- 配置：PC（1025 以上）・タブレット（768〜1024、1 列で画面幅の 70% 以上）・スマホ（767 以下）で変える
- 設計書：`SPEC.md`（色・書体・寸法と、STEP 3 で決めたこと・STEP 4 で直したこと）／写真：`photos.txt`（Unsplash）／置換表：`terms.md`
- お店の中身：`samples/<店>/wa21-content.json`（店名・文・スパイスの一覧と色・カレー・あいがけ・値段・案内の行）。道具に店の中身は書かない

## 作り方
```
node tools/wa21-gen.mjs <店のID>
node tools/build.mjs samples/<店のID>
node tools/wa21-finish.mjs <店のID>
node tools/wa21-check.mjs <店のID>
```
写真を差し替えるときは `photos.txt` の URL を変え、`samples/<店>/media/ast_ph<枠>.webp` を消してから gen を流す（無い写真だけ取りに行く）。
スパイスの数は 2 の倍数がきれいに並ぶ（PC・タブレットは 2 列）。カレーの「使うスパイス」には、スパイスの一覧にある名前だけを書く（無い名前は gen が止める）。
