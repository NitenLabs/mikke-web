## 5. 色のコントラスト（WCAG の相対輝度で計算）
| 組み合わせ | 比 | 4.5:1 |
|---|---|---|
| 白 #FBFAF7 と 醤油 #7A4A2A | 7.08 | 満たす（見出し・線・本文にも可） |
| 白 #FBFAF7 と 黒 #161616 | 17.34 | 満たす |
| 白 #FBFAF7 と 青竹 #6E8B5A | **3.66** | **満たさない** |
| 黒 #161616 と 青竹 #6E8B5A | 4.74 | 満たす（黒の帯の上の青竹の文字は可） |
| 醤油 #7A4A2A と 黒 #161616 | 2.45 | 満たさない（重ねない） |
| 醤油 #7A4A2A と 青竹 #6E8B5A | 1.94 | 満たさない（重ねない） |
- 青竹の扱いの案：(a) 白の上では文字に使わず、小さな差し色（点・短い線・札の地に白抜きでない飾り）だけにする（3:1 以上なので、太い大きな文字・図の線なら WCAG の大きい文字の基準 3:1 は満たす）。(b) 白の上で文字に使うなら **#5A7549（白の上 4.94、黒の上 3.51）** に寄せる（#5E7A4E は 4.60 で境目に近い）。黒の帯の上は元の #6E8B5A のまま（4.74）
- 白の文字を醤油の面に載せる場合も 7.08 で可。黒の帯の上の醤油色の文字は不可（2.45）
