# wa-23：中華そば 芦の葉 の型（G037・lane3。ID ashinoha）。参考は seavege-stand.com（シーベジスタンド）

白い地 #FBFAF7 に黒 #161616 の文字、醤油 #7A4A2A の英字・番号・線・ボタン、青竹 #6E8B5A の小さな差し色。黒は営業の帯とフッターだけ。Yuji Syuku（店名・大見出し）＋ Zen Kaku Gothic New（本文）＋ Archivo（欧文・数字）。澄んだ一杯の中華そば・ラーメンの個人店向け。
見せ場は「四つの素材」（スープ・かえし・麺・具を 1 枚ずつのパネルにし、角丸の札の丸い写真・素材の名前と産地の表・両脇の番号つきの目次で見せる。PC とタブレットでは、パネルが画面に留まり、次のパネルが重なって上がる。JS なし）。

- 段の順：ヘッダー → 最初の画面（店名とコピー＋真上の一杯）→ 黒の営業の帯 → 四つの素材（頭＋パネル 4 枚）→ お品書き（生成りの面に大きな「そば」、写真の札 3 枚・ほかのそば・追加とごはん）→ 店のこと（左に寄せたカウンターの写真）→ ご案内（左に地図、右の面に表と電話のボタン）→ フッター（黒の帯）
- 配置：PC（1025 以上）・タブレット（768〜1024、1 列で画面幅の 70% 以上）・スマホ（767 以下）で変える
- 設計書：`SPEC.md`（色・書体・寸法・文言・決めた所・組み立て方）／STEP 1 の記録：`step1-notes.md`／写真：`photos.txt`（Unsplash）／置換表：`terms.md`
- お店の中身：`samples/<店>/wa23-content.json`（店名・文・四つの素材と表・品書き・値段・案内の行・写真の alt）。道具に店の中身は書かない

## 作り方（STEP 3 で道具を作る）
```
node tools/wa23-gen.mjs <店のID>
node tools/build.mjs samples/<店のID>
node tools/wa23-finish.mjs <店のID>
node tools/wa23-check.mjs <店のID>
```
写真を差し替えるときは `photos.txt` の URL を変え、`samples/<店>/media/ast_ph<枠>.webp` を消してから gen を流す（無い写真だけ取りに行く）。
四つの素材のパネルは 1〜6 枚、表の行は 1〜5 行で崩れない。品書きの写真の札は 0〜3（それより多い品は「ほかのそば」の行へ）。
写真の明るさをそろえるときは `samples/<店>/wa23-content.json` の `filters` に `{ "shio": "brightness(1.1)" }` の形で書く（finish が CSS に出す）。
