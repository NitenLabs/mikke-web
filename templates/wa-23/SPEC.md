## 11. STEP 3 の組み立て方（wa-21 と同じ方式。店の ID で動く道具）
```
node tools/wa23-gen.mjs <店のID>
node tools/build.mjs samples/<店のID>
node tools/wa23-finish.mjs <店のID>
node tools/wa23-check.mjs <店のID>
```
- **`tools/wa23-gen.mjs <店のID>`**：この SPEC の数値から `samples/<店>/` の shop.json・theme.json・assets.json・site.json と、タブレットの配置・飾りの表 `wa23-layout.json` を作る。店の中身は `samples/<店>/wa23-content.json` だけから読み、**道具に店名・品名・素材・産地・値段を書かない**
  - `wa23-content.json` の形（案）：`name`・`nameKana`・`nameEn`・`genreWord`（「中華そば」）・`genreDetail`・`town`・`geo`・`phone {display, digits}`・`week`／`periods`・`hoursNote`・`seats`・`labels`（ナビ・ボタン・メニューのボタン）・`fv {en, copy, note}`・`band [..]`・`elements {heading, en, lead, items: [{en, name, text, photo, sub?: {photo, caption}, rows: [[素材, 産地], ..]}]}`・`menu {label, big, small, lead, photoItems [..], moreLabel, more [..], sidesLabel, sides [..], note}`（品は `{id, name, desc, price, photo?}`）・`about {label, heading, paras, photo}`・`info {label, heading, rows, button}`・`photos {枠: [slot, alt]}`
  - 写真は `templates/wa-23/photos.txt` の URL から取り込む（`samples/<店>/media/ast_ph<枠>.webp`。無い写真だけ取りに行く。wa-21 と同じ）。`elements.items[].photo`・`menu` の `photo` に、photos.txt に無い枠を書いたら止める
  - パネルの数・表の行の数・品の数から段の高さと目次の行を計算する（6 章の範囲。範囲外は止める）
  - shop.json：`isSample: true`・`demo: true`、営業は曜日ごと（火曜休み、ほかは昼と夜）、「スープがなくなり次第終了」は `hours.note`、席は `facilities.seats`。品は 4 区分（そば・ほかのそば・追加とごはん）。品の ID は形の決まり（4 字以上）に合わせる
  - データの太さは 300〜700・900（wa-21 の記録）なので、Archivo 600・Zen 700 はそのまま、Yuji Syuku は 400
- **`tools/wa23-finish.mjs <店のID>`**：描画エンジンに無いものを `dist/<店>` に足す：①四つの素材のパネルを `<div class="wa23-stack">` で包み、`position: sticky; top: ヘッダーの高さ`（PC `@media (min-width:1025px) and (min-height:860px)`、タブレット `(min-width:768px) and (max-width:1024.98px) and (min-height:960px)`）、パネルの地を不透明に、`@media print` では留めない／②札の角丸 40・32、丸い写真（`border-radius: 50%`）と niboshi の地の色の輪、`.el-shape-circle{border-radius:50%}`（wa-21 の教訓。点も丸にする）／③目次の今の行の色（gen が要素ごとに色を決めるので、finish は `cursor: default` と `pointer-events: none` だけ）／④帯の青竹の点、ホバーの下線、ヘッダーの下の線／⑤地図の埋め込み（緯度経度＋`z=16`＋`hl=ja`）／⑥h1 の読み上げ（「中華そば 芦の葉」になるよう、上の小さな「中華そば」は見た目だけにして h1 の中に読み上げ用の語を足す。wa-21 と同じ）／⑦全面のメニューの電話のボタン／⑧`word-break: auto-phrase`・`font-synthesis: none`・数字の形／⑨タブレットの配置（768 の設計を rem で伸ばす）／⑩写真の `object-position` と、点検で決めたときだけ `filter`。**データの形（schema）は変えない**
