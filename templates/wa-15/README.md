# wa-15：天ぷら 杜若（かきつばた）の型（G031・lane3）

明るい白木の地に藍の見出しと黄金の線。天ぷら・和食のカウンター店向け。
見せ場は「おまかせの流れ」の段（左に縦書きの見出しと縦長の写真、右に番号・品の種類・品名を順に並べる）。

- 段の順：最初の画面（縦書きのコピー＋大きな写真）→ おまかせの流れ → 軽やかな衣 → 目の前の揚げ鍋 → お品書き（昼・夜・単品の3列）→ ご案内（地図）→ ご予約（電話）→ フッター
- 配置：PC（1025 以上）・タブレット（768〜1024、1列で画面幅の 70% 以上）・スマホ（767 以下）で変える
- 設計書：`SPEC.md`（色・書体・寸法と、STEP 3 で決めたこと）／写真：`photos.txt`（Unsplash）／置換表：`terms.md`
- お店の中身：`samples/<店>/wa15-content.json`（店名・文・おまかせの流れ・品書き・値段）。道具に店の中身は書かない

## 作り方
```
node tools/wa15-gen.mjs <店のID>
node tools/build.mjs samples/<店のID>
node tools/wa15-finish.mjs <店のID>
node tools/wa15-check.mjs <店のID>
```
写真を差し替えるときは `photos.txt` の URL を変え、`samples/<店>/media/ast_ph<枠>.webp` を消してから gen を流す（無い写真だけ取りに行く）。
