# SPEC：wa-16（参考：https://wankosoba.jp/ 、取得日 2026-11-10）

G030「手打ち蕎麦 くぬぎ」（架空の手打ち蕎麦店）の型。実測は `refs/azumaya/`（コミットしない）。
参考は MUUUUU.ORG と SANKOU! の両方に載っている蕎麦店（そば処 東家）のサイト。MUUUUU の蕎麦店はほかに本家尾張屋（サイトが閉じてお知らせだけ）とそば処庄司屋（古い作りで写真の格子だけ）を測って外した。SANKOU! は 403 で読めず、検索で掲載だけ確かめた。
**手順書 1章の例外**：ギャラリーの指示により色と書体はお店の設定を使う（参考の #002B82・赤・#ECECEC と Noto Sans JP は使わない）。参考の縦書き・わんこ蕎麦の演出・文章・写真・ロゴは持ち込まない。

## 2. 構造の数値（参考の実測から）
- 中身の幅 1200（左右 120）＝参考の PC の主な幅（1200・左右 120）。スマホは左右 24・幅 342（参考は 10〜33 のばらつき）
- お品書きの格子：2 列・列幅 588・間 24（参考の `2列|幅1200|列幅588|間隔24`）
- ボタン：角丸 999px（参考のピル形 角丸 30px）、輪郭のボタンは線 1.5px（参考は 2〜3px）。塗りのボタンは藍
- 写真の角は丸めない（参考の角丸 0）
- 文字：見出し Zen Antique Soft（大見出し 40〜44・店名 120）、本文 Noto Serif JP 15〜16。小見出しは 14px・字間 0.3em（参考の字間の大きい小見出しの性格）
- Zen Antique Soft は字の箱が高いので、行の高さを 1.45 倍前後にする（重なりの検査で決めた）
- 折り返し：`.lb{word-break:auto-phrase}`（文節で折り返す。wa16-finish）
- ブレークポイント：1025 未満は sp のデータを広げてタブレットの配置（`tools/wa16-finish.mjs`）。768〜1024 の列は画面幅の 70% 以上（実測 88%）

## 4. 隣接衝突の対策
全面の写真は使わない。面の色は生成り → 淡い生成り → 生成り → 蕎麦殻色 → 生成り → 藍 で、隣り合う段の色を必ず変える。

## 6. 新規設計した段
- **三つの手仕事（見せ場）**：参考の写真の格子の「同じ大きさの写真を等間隔に並べる」性格だけを借り、工程の番号（一・二・三）と次の列までつながる線で「挽く → 打つ → 盛る」の流れ（G042 で三つ目を「茹でる」から「盛る」に変えた）を見せる。PC・タブレットは横に三列、スマホは写真 140×200 と文を横に並べた三段
- **一品と酒**：日本酒の写真を品のデータに結びつけ（repeater）、写真の無い一品 3 つを行で出す。写真つき 4＋行 2＋酒 1＋行 3 で全 10 品を重複なく出す

G042（相談役の点検）で sr・s3・s1・sk を替えた（黄色い縮れ麺・ラーメンの湯切りざる・分かりにくい水車の石臼・しまってある器に見えるぐい呑み → 蕎麦屋の写真に）。石臼（s1）は灰色で冷たいので CSS で `sepia(.3) brightness(1.08)`、徳利（sk）は `sepia(.18)` をかけて生成りの面に寄せた（`wa16-finish`）。

## 8. 開いた切り抜きと理由
参考の PC の全体像（縮小 360px）だけ。段の並びと写真の格子の位置を確かめるため。

## 8-2. リンク
電話の番号・ボタン・フッターのナビ・ヘッダーの店名は `style.link`（共通の道具 f3b3baa で `<a>` になる）。`wa16-check` が 14 幅で `<a>` であること（電話は `tel:`）と、押した位置で最前面であることを確かめる。

## 8-3. 検査の許容
スマホのご案内とフッターは描画の伸び縮みで設計より約 10px 高くなるため、`wa16-check` の高さの許容は ±10（wa-14 と同じ）。
