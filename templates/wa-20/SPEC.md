# SPEC：wa-20（参考：https://gran-burger.com/ 、取得日 2026-11-10）

G036「洋食の店 すずかけ」（架空の昭和から続く街の洋食屋。指示の仮の店名は「洋食の店 ポプラ」。ID は `popura` のまま）の型。実測は `refs/granburger/`（`report.md`・`menu.json`・`selection.md`。コミットしない）。
**参考の選び方**：MUUUUU.ORG の飲食の分類（2 ページ・186 件）と SANKOU! の「カフェ・飲食店」1 ページ目（81 件）・「料理・食品」1 ページ目を見て、洋食屋・グリル・オムライス・ハンバーグの店は 1 件も無かった（SANKOU! の 2・3 ページ目と検索のページは 403。回避はしていない）。そこで指示の第二候補（どちらかに載る、同じ系統の質の高い個人店）から、SANKOU! に載る唐津の 1 店舗のハンバーガーの店を選んだ。両方には載っていない。
選んだ理由：代表の品の段が「大きな写真＋名札＋2px の枠の説明の箱」を一品ずつ組み、一品目は写真を中央に大きく・箱は全幅、二品目は写真と箱を左右に並べる。これを「当店の三つの定番」にそのまま移せる。
**手順書 1章の例外**：ギャラリーの指示により色と書体はお店の設定を使う（参考の生成り #E0DBCE・墨 #111111・オレンジ #FF4E08 と Anton・Noto Sans JP 900 は使わない）。参考の文章・写真・ロゴ・横に流れる演出・採用（RECRUIT）の段・写真の帯は持ち込まない。

## 4. 隣接衝突の対策
面の色は クリーム → 淡い生成り → 紺 → クリーム → 赤 → 紺 で、隣り合う段の色を必ず変える。全面の写真は使わない。白南風（純喫茶・深緑）とは、深緑を使わず、赤と紺・金の線・番号の札で洋食屋の献立の性格にした。

## 6. 新規設計した段
- **当店の三つの定番（見せ場）**：品ごとの repeater（`sigPick`）。写真・赤の番号の札・2px の紺の枠の箱（品名・値段・説明）をカードの中の要素で重ねる。PC は一皿目が中央の大きな写真と全幅の箱、二・三皿目が左右を入れ替えた組。タブレットは三皿とも写真と箱の左右（二皿目は入れ替え）、スマホは写真の下に箱
- **お品書き**：正方形の写真のカード 3 枚（`menuPick`）と、写真の無い品の行（`rowPick`）
- **すずかけのこと**：大きな創業の年と紹介 2 段（`aboutBody`・`aboutBody2`）
- 全 8 品を重複なく出す（定番 3・お品書きのカード 3・行 2）
