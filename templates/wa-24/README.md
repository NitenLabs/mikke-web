# wa-24：BAR KAIRO の型（G039、lane2。ID kairo）。参考は grandpalace-hirosaki.jp（グランドパレス弘前）。

深い紺の地に琥珀の見出しと値段、真鍮の 1px の線、煙色の文字。Italiana・Kaisei Tokumin。カクテルバー・オーセンティックバーの個人店向け。
見せ場は「今宵の一杯」（季節の三杯を 2 列の千鳥のカードで、写真・名前・英字・材料・一言・値段。右端に縦の巨大欧文「Tonight」）。PC・タブレットは左に固定の縦の札の列（今いる段を琥珀と左の線で示す）、スマホはヘッダーの下に横の札の行。

- 段の順：ヘッダー → 最初の画面（縦書きのコピーと横長の写真、英字の 3 行）→ 今宵の一杯 → カウンター（縦書きの見出し・紹介文・写真・数字の 3 列）→ 品書き（写真付きの 3 列のカードと 1px の線で区切った 3 行）→ 案内と地図 → フッター（左上の角 80、「20歳未満の方の飲酒はお断りしています。」）
- 道具：`node tools/wa24-gen.mjs <店>` → `node tools/build.mjs samples/<店>` → `node tools/wa24-finish.mjs <店>`。検査は `node tools/wa24-check.mjs <店>`（15 幅。タブレット 768・834・1024 の列の幅、`<a>` と tel:、ナビとボタンの重なり、押せない飾りのボタン、カードの中で切れる物、ボタンの文字が札の外に出る物）
- 店ごとの中身：文言・英字の札・カードの割り当ては `samples/<店>/wa24.json`、品名・説明・材料・値段は `samples/<店>/shop.json` の品、写真は `photos-<店>.txt`
