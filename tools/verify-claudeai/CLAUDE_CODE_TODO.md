## その1：Claude.ai の確認スクリプトを、この Mac で走らせられるようにする

Claude.ai の確認スクリプト6本を `tools/verify-claudeai/` に置きました。この Mac でも走らせられるようにしてください。手順は次のとおりで、途中で引っかかったら止めて報告してください。

**1. 空きと Python を確かめる**
- `df -h ~` で空きが 2GB 未満なら、何も入れずに止めて報告
- `python3 --version` で 3.9 以上があるか確かめる。「デベロッパツールを入れますか」という画面が出たら、**入れずに**止めて報告

**2. 作業フォルダの外に、専用の Python の環境を作って入れる**

```
python3 -m venv ~/.venvs/mikke-verify
~/.venvs/mikke-verify/bin/pip install playwright
~/.venvs/mikke-verify/bin/playwright install chromium
```

Chromium だけ入れる。node の Playwright が使っている Chromium と同じ版なら、取り込みは省かれる。

**3. 試しに走らせる**

`tools/verify-claudeai/` の6本を、`refs/compare/layout/playground22_single.html` に対して1本ずつ走らせる。

- **同時に2本走らせない**
- `verify_extra_photo.py` を `verify_extra_text.py` より先に走らせる（試験用の写真を作るため）
- `verify_playground.py` は8〜9分かかるので、裏で走らせて待つ
- 結果は `refs/compare/layout/playground22/verify/` に1本ずつ log で残す

**4. スクリプトは直さない**

不合格が出ても、スクリプトや試験の期待は書き換えない。Mac と Claude.ai の環境では書体が違うので、文字の幅で決まる数字が少しずれることがある。そう思われる所は、所見として分けて書く。

**5. 報告**

入れた物の大きさ、6本それぞれの合格数と不合格の行。

**これから先の作業票では、報告の前にこの6本を走らせ、結果を報告に入れること。**

## その2：22a' として X29・X30 を直す

22a を Claude.ai が確認しました。22b へ進む前に、22a' として次の2つを直してください。

**X29（重い）**：縦に積んだ部品を少しだけ（40px の内側で）ドラッグしても、動かない。`dropTarget()` が `'reorder'` を返し、`ops()` も増えない。例：特集の見出しを右へ 12・下へ 8、区切り線を下へ 10。試験台20b では M1 で動いていた。

- `verify_playground.py` の Q1・R1・R8・W1・W3・W5・W9・W12・Y1・Z1〜Z3（PC 29 個）と、`verify_touch.py` の E5 が不合格
- 原因は X27 の直しで、「帯の中＝並び替え」を M1 の判定より先に見ていること
- 直し方：判定の順は試験台20 のとおり、「40px の内側でずらしただけ（M1）」を一番先にする。そのうえで、**自分の元の場所の上下の帯は相手にしない**（試験台20 の作業票 4.2 の 3）。帯の判定を「② の箱の中」より先に見るのは、そのまま

**X30（小）**：品の1件の中の写真を右クリックすると、「最前面へ移動 ▸」「最背面へ移動 ▸」が出る。作業票22 の 8章の 5 のとおり、出さない。

直した後は、L 系の試験に加えて、**`tools/verify-claudeai/` の6本を走らせて**から報告してください（その1が終わっていれば）。W23 はマウスの試験なので、「再現なし」にせずに走らせてください。
